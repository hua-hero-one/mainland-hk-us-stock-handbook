## 2. 编写口径说明

本手册在编写时遵循以下原则，读的时候也请带着这些预期：

| 口径 | 说明 |
| --- | --- |
| **费率给量级** | 除规费（印花税 0.1% 等）外，佣金、平台费、点差给的是**区间**，因为各券商差异大且频繁调整 |
| **规费给具体值** | 印花税、交易征费、SEC Fee 等**法定或交易所固定收取**的项目给出具体数字，但标注"以最新公告为准" |
| **门槛给常见值** | 券商的资产门槛、初始入金门槛给常见范围 |
| **政策变化标注** | 所有"政策频繁调整"的地方都用 ⚠️ 显式标出，并给出"向券商书面确认"的动作建议 |
| **不荐股、不荐券商** | 本手册不做任何券商排名或推荐，只提供**选择框架**。费率表和政策请自行核实 |
| **税务部分保守表述** | 涉及税务争议的地方明确说明"实务现状"与"法条要求"的差异，建议咨询执业人士 |
| **红线明确** | 地下钱庄、虚拟货币出金、借用额度、伪造材料、代客理财分成等一律标 🚫 |

### 已知的局限

1. **本手册不掌握任何券商的实时内部政策。** 券商的客户准入规则只有客户经理能告诉你。
2. **外汇与税务的具体执行在各地银行/税务机关有差异。** 遇到分歧以主管机关口径为准。
3. **篇幅所限，未覆盖**：期权策略详解、债券投资、REITs、加密资产证券、税务居民身份筹划、退休账户（IRA）等。
4. **未做投资建议。** 所有例子中的收益假设仅用于说明成本结构。

## 3. 更新机制

### 3.1 什么情况下应该更新本手册

- 国家外汇管理局调整个人购汇/结汇规则
- 中国证监会调整对境外券商展业的监管口径
- 财政部/税务总局调整境外所得个税政策
- 港交所调整交易费用（印花税、交易费、交收费）
- SEC/FINRA 调整规费费率
- 美国与中国税收协定条款修订
- 券商大面积调整内地居民准入政策

### 3.2 建议的复核节奏

| 频率 | 复核内容 |
| --- | --- |
| **每次准备开户前** | 券商准入政策、入金通道、费率表 |
| **每年年初** | 个人购汇额度余量、账户状态、税务文件、券商公告 |
| **每年 Q4** | 汇总全年对账单，评估申报义务 |
| **看到监管公告时** | 立即复核第 08 章 |

### v1.3.0 — 新增第 13 章「网络环境」与工具推广位

新增 `docs/13-network-environment.md`，解决一个此前散落在各篇里、没有系统讲过的问题：
**部分券商/银行的 App、开户页面、验证码接口在内地网络下无法完成提交。**

- **现象清单**：提交转圈、验证码收不到、上传证件失败、"当前地区不支持"、App 闪退
- **全局 vs 规则模式**：开户必须全局，因为提交是多环节串联（App → 对象存储 → 风控接口 → 短信接口 → 提交接口），任一环节走直连就会呈现出口 IP 不一致
- **自证方法**：App 内 IP 与 `ipinfo.io` 的 IP 必须一致
- **核心原则**：网络环境与申报信息必须自洽——⚠️ **IP 归属地 ≠ 居住地**，用境外节点**不意味着可以把居住地址申报成"现居香港"**
- **各平台表现表**：致富 / 盈立 / 复星 / 汇丰 / 中银 / 恒生 / ZA Bank / WeLab / 纯美股券商
- **实操清单**：选港新日节点、**全程不换 IP**、App 与浏览器同出口、中途不切节点
- **🚫 红线清单**：不伪造居住地、不用免费/公共节点（证件与验证码会泄露）、不多设备多地区同登、不用 VPN 规避反洗钱审查
- **🎁 工具推广位**：CloudSS（`aff=10343`），含试用 $0.2、套餐 $9.90/月起、节点地区、专用客户端与订阅导入说明
