# 09 风险与避坑

> 本章目标：把"最坏情况"提前想清楚，知道怎么识别骗局。
> **开户和入金只是第一步。真正让人亏钱的通常是后面。**

---

<a id="risks-1-seven"></a>

## 1. 七类必须知道的风险

### 风险 1：平台合规与清退风险 ⚠️ 高

**是什么**：境外券商面向中国内地居民的展业状态是"灰色"的。监管政策变化时，平台可能：
- 停止接受内地居民新开户
- 限制内地居民入金
- 关闭内地居民的交易权限
- 直接清退账户（清退时通常按市价平仓，然后退还资金）

**为什么会发生**：
- 中国证监会持续要求券商不得未经许可向境内居民展业
- 香港证监会与内地监管机构的沟通协调
- 平台自身为降低合规风险而主动收缩

**怎么应对**：
| 做法 | 说明 |
| --- | --- |
| **只放一部分资金在境外平台** | 不要把全部身家在境外券商 |
| **优先选有大量其他地区客户的大型平台** | 客户地域越分散，越不可能整体退出某单一市场 |
| **不要用杠杆** | 平台清退时被强平，是最坏的组合 |
| **保持流动性** | 关注平台的最新公告与 App 内通知 |
| **设置提醒** | 关注平台邮件、官网公告、相关监管动态 |
| **别把平台当作唯一的托管方** | 长期持有可以考虑转托管到其他机构（视平台是否支持） |

> ⚠️ **没有平台能保证"永远不退出内地市场"。** 任何声称能保证的说法本身就值得怀疑。

---

### 风险 2：市场风险 ⚠️ 高（必然存在）

**美股/港股年化波动**，历史参考：
- 标普 500 历史最大回撤：2008 年金融危机约 **-57%**，2020 年 3 月约 **-34%**，2022 年约 **-25%**
- 恒生指数历史最大回撤：1997 年亚洲金融危机约 **-65%**，2008 年约 **-53%**
- 个股可能归零（港股尤其常见）

**杠杆会放大一切**：
- 港股孖展 2 倍、牛熊证可归零
- 美股期权买方的**时间价值衰减**，多数期权在到期时价值为 0
- 窝轮、牛熊证有**强制收回（Mandatory Call）**条款，可被发行人提前收回

**具体坑**：
- 港股新股**暗盘破发**、上市首日暴跌（近年港股新股首日破发率不低）
- **融券（做空）**在牛市中会爆仓
- **期权卖方**（收权利金）在剧烈行情中可能巨额亏损

---

### 风险 3：汇率风险 ⚠️ 中

| 敞口 | 影响 |
| --- | --- |
| 人民币升值 | 以美元/港币计价的资产折回人民币缩水 |
| 人民币贬值 | 折回人民币时增值（但这不改变美元本身的购买力） |
| HKD/USD 挂钩 | 港币与美元挂钩（联系汇率 7.75–7.85），港币资产 ≈ 美元资产 |

**实测影响**：
- 2015–2016 年人民币对美元贬值约 15%，同期港股（美元计价）上涨约 20% → **港股投资者以人民币计实际赚约 38%**
- 2017–2020 年人民币升值约 12%，港股横盘 → **以人民币计亏损 12%**

> 💡 **结论**：港股/美股投资里，**汇率贡献的损益常常超过你选的股票本身的损益**。做决策时要算总收益，别只看指数涨跌。

---

### 风险 4：资金流动性与出金风险 ⚠️ 中

- 境外券商出金通常 T+1 到 T+5 到账，遇汇率管制/节假日更久
- 大额出金可能触发银行问询，需要提供证明材料
- 部分平台出金通道本身可能因政策收紧而变慢或关闭
- **最坏情况**：你赚了钱，但拿不回来

**应对**：
- 预留一部分流动资金在境外账户（不投任何东西）
- 每年至少做一次小额出金测试，确认通道通畅
- 保存好所有对账单

---

### 风险 5：操作与系统风险 ⚠️ 中

| 坑 | 说明 |
| --- | --- |
| **忘记过 T+2 卖出的钱没到账就下买单** | 港股现金账户卖出后资金 T+2 可用；美股 T+1 |
| **港股交易日与内地不同** | 港股在内地休市的日子照常开市（复活节、耶稣受难节等） |
| **汇率时点** | 美股交易时段是北京时间的深夜/凌晨 |
| **条件单/止损单失效** | 部分平台的止损不保证成交（跳空时按开盘价成交） |
| **公司行动未确认** | 拆股、派息、供股默认可能"不参与" |
| **App 版本/地区问题** | 改区安装的 App 可能无法登录或无法提现 |
| **误操作市价单** | 港股/美股部分标的无涨跌幅限制（或有但很宽），低流动性股票市价单可能成交在极差价格 |

---

### 风险 6：税务风险 ⚠️ 低（但不可忽视）

详见 [第 08 章](08-tax-compliance.md)。要点：
- 居民个人的境外所得有申报义务
- 实践中征管较少，但金额大/频繁者风险上升
- **CRS 让"看不到"不再是理由**

## 2. 诈骗识别清单

### 2.1 十大红旗 🚩

| # | 红旗 | 为什么危险 |
| --- | --- | --- |
| 1 | **"内部渠道""包开户""包过"** | 正规券商不需要这么说 |
| 2 | **要求转入个人账户 / 私人微信 / 支付宝** | 资金脱离监管，平台出问题你一无所有 |
| 3 | **宣称"稳赚""保本高收益""年化 30%+ 无风险"** | 违反证券法规，典型骗局特征 |
| 4 | **拉你进荐股群 / 老师带单 / 代客操盘** | 荐股违法，代客理财违法，分成更违法 |
| 5 | **要你提供短信验证码 / 交易密码** | 🔴 **任何索要验证码的都是诈骗**。正规机构永远不会要 |
| 6 | **用 USDT / 虚拟货币入金** | 中国境内虚拟货币业务非法；且常混入诈骗资金 |
| 7 | **仿冒官网 / 仿冒 App / 仿冒客服** | 检查域名和备案，客服只认官方 App 内入口 |
| 8 | **承诺"高额返佣""代理开户提成"** | 可能构成协助非法经营 |
| 9 | **催促"今天最后一天，不马上打款就失效"** | 制造紧迫感是诈骗的通用手法 |
| 10 | **晒盈利截图、"跟投"群、直播喊单** | 截图可以造假，真人带单骗局极高发 |

### 2.2 五个验证动作 ✅

```
1. 查牌照：香港 SFC 公众登记册 / 美国 SEC IAPD / FINRA BrokerCheck
   → 输入公司名，确认牌照状态、持牌法团名称是否与合同一致

2. 查域名：官网域名注册时间、正规的 https 证书
   → 克隆站通常注册时间很短

3. 查收款方：汇款收款人必须是持牌机构的官方账户
   → 任何个人名下的账户都直接拒绝

4. 问细节：佣金怎么算、最低收费多少、规费清单、怎么出金
   → 骗子答不上来或含糊其辞

5. 反向测试：挂断后，用官网公布的客服电话主动打回去
   → 验证刚才的"客服"是不是真的
```

### 2.3 已经遇到疑似诈骗怎么办

```
1. 立即停止一切转账，不要"再追回一点"
2. 保存所有证据：聊天记录、转账凭证、对方账号、网址
3. 拨打 110 报案；同时联系银行申请紧急止付/冻结
4. 如果是虚拟货币出金，立刻向交易平台客服申请"争议冻结"
5. 涉及外汇违规，同时向国家外汇管理局反映
6. 涉及虚假证券荐股，向中国证监会 12386 举报
7. 金额大 → 委托专业反诈律师
```

> ⚠️ **黄金时间**：转账后**立即**联系银行止付。资金一旦进入多层转账账户，追回难度呈指数级下降。

## 3. 给新手的仓位建议

### 3.1 先想清楚三件事

```
① 我这笔钱多久不用？（< 2 年 → 别投波动资产）
② 我能承受的最大亏损是多少？（不是"心理承受"，是"实际能承受"）
③ 如果它明天跌 50%，我的生活和判断力会不会受影响？
```

### 3.2 一个保守的起步框架

| 阶段 | 建议 |
| --- | --- |
| **第 0–3 个月** | 只用**总可投资资产的 10%–20%** 试水，**只买宽基 ETF**（如 VOO、VTI、3033.HK、2800.HK 之类），**不加杠杆**，目的是熟悉流程和手感 |
| **第 3–12 个月** | 确认你能完整走完"入金→交易→卖出→出金"闭环，且心态稳定，再考虑提高比例 |
| **第 1 年后** | 建立自己的配置方案，考虑个股、分批建仓、再平衡 |

### 3.3 几条硬性纪律

| 纪律 | 说明 |
| --- | --- |
| **不加杠杆**（至少第一年） | 杠杆会把"暂时回撤"变成"永久亏损" |
| **单一股票不超过总仓位 10%** | 单一行业不超过 25% |
| **先看指数 ETF，再看个股** | 大部分人应该以指数为主 |
| **不用杠杆买"更看好的板块"** | 两者叠加会放大到无法承受 |
| **不碰不懂的东西** | 窝轮、牛熊证、期权、加密货币合约——**看不懂就不要买** |
| **先做小额完整流程** | 用最小可行金额走完全流程，比看 100 篇攻略有用 |
| **写下你的卖出条件** | 事前写下，事后照做 |
| **不看盘的时间可能比看盘更值钱** | 频繁查看会诱发过度交易 |

### 3.4 关于"打新"

港股打新（IPO 申购）是很多内地投资者的主要理由。但要清楚：
- **中签率通常很低**（热门股可能只有个位数百分比甚至更低）
- **暗盘与首日波动极大**，破发是常态
- **中签后不“中就赚”**：很多人在暗盘/上市首日就卖出，中签收益可能很薄
- **融资打新会放大风险**（用了杠杆）

## 4. 一张检查表

```
[ ] 我能承受这笔钱 50% 的亏损而不影响生活
[ ] 我用的是宽基 ETF 而不是不懂的产品
[ ] 我没有使用杠杆（至少第一年）
[ ] 我验证过券商牌照（SFC/SEC/FINRA）
[ ] 我的资金只经过"我的银行 → 我的账户 → 我的券商"
[ ] 我确认过出金通道并做过小额测试
[ ] 我保存了所有对账单和交易记录
[ ] 我知道如果券商清退我的钱会怎么回来
[ ] 我没有加入任何荐股群 / 代客群
[ ] 没有任何人向我索要过验证码或密码
[ ] 我设置了年度提醒：核对持仓、税务文件、账户状态
```
