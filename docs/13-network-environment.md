# 13 网络环境与全局模式

> 部分券商与银行的 **App、开户页面、验证码接口在内地网络下无法完成提交**。
> 这一章讲清楚：哪些是**技术问题**（用网络环境解决）、哪些是**申报问题**（必须如实填，工具帮不了也不该帮）。

---

## 一、为什么需要：技术性阻断

| 现象 | 原因 |
| --- | --- |
| 页面能开，但**提交后一直转圈** | 风控/反爬接口在境外网段才正常响应 |
| **验证码收不到** | 短信/邮件接口按出口 IP 做频率与地域判断 |
| **App 闪退或功能灰掉** | 商店区域与 IP 归属地不符，或 App 做了地域限制 |
| 提示「**当前地区不支持**」 | 服务端按 IP 归属地直接拒绝 |
| **上传证件一直失败** | 对象存储直传域名在内网不可达 |

**解法**：让设备走**境外节点 + 全局模式**。

> ⚠️ **三句话底线**
> 1. 网络环境只解决"打不打得开"，**不解决"能不能如实申报"**。
> 2. **IP 归属地 ≠ 你的居住地**——用香港节点打开 App，不等于可以把自己申报成"现居香港"。
> 3. **免费节点会看到你的流量**——证件照片、验证码、银行卡号都在里面。

---

## 二、全局模式 vs 规则模式

| 模式 | 含义 | 用途 |
| --- | --- | --- |
| **规则模式** | 只有命中的域名走代理 | 日常浏览 |
| **全局模式** | **所有流量**都走代理 | ✅ **开户 App、开户页面、验证码接口** |

**为什么开户必须全局？** 因为提交是**多环节串联**的：App → 对象存储（传证件照）→ 风控接口 → 短信接口 → 提交接口。**只要有一个环节走直连，出口 IP 在服务端就会呈现不一致**——这正是风控最容易抓的信号。

> 🔍 **自验**：App 内"我的/设置"看到的 IP，与浏览器打开 `ipinfo.io` 看到的 IP，**必须一致**。

---

## 三、核心原则：网络环境与申报信息必须自洽

反洗钱审查会交叉比对**四类信息**：

```
① 出口 IP 归属地     ② 申请表填写的居住地址
③ 上传证件上的地址   ④ 出入境记录 / 住址证明
```

| | 做法 | 后果 |
| --- | --- | --- |
| ✅ **正确** | 用境外节点**解决访问问题**；居住地址**照实填内地**；税务居民**如实申报**；合规申明**照实签署** | 合规，通过率高 |
| 🚫 **错误** | 因为用了香港节点，就把居住地址申报成"现居香港" | 地址与身份证/流水对不上 → 补件或被拒；开户后被查出 → **账户限制或清退** |
| 🚫 **错误** | 在境外网络下申报为"非内地税务居民" | 股息预扣从 10% 变 30%，且属不实申报 |

> ⚠️ 网络环境**不可见地**影响审核是常态（App 自动记录），但**地址申报是书面的、可被举证的**。两者不一致时**永远以书面申报为准**，而书面申报必须为真。

---

## 四、各平台实际表现

> ⚠️ 经验观察，非官方口径，平台随时会改。**开户前先小成本试一次**。

| 平台 | 内地直连 | 全局模式 | 备注 |
| --- | --- | --- | --- |
| **致富证券** | 资料页可开，**提交环节易卡** | 建议 | 用户反馈中明确提到过 |
| **盈立证券 uSmart** | App 内开户入口**需境外网络** | 建议 | 内地直连常见白屏 |
| **复星国际证券** | 香港 App 需境外网络 | 建议 | 且**须身处香港**完成，见 [12 篇](guides/12-broker-fosun.md) |
| **汇丰 / 中银香港 / 恒生** | App 需境外网络 | 建议 | 且**须身处香港**完成 |
| **ZA Bank / WeLab** | 需境外网络 + **人在港** | 必须 | 定位校验会拒绝内地 GPS |
| **纯美股券商（IBKR 等）** | 注册/入金可直连 | 一般不需要 | **视频核验**环节常需 |

## 五、实操清单

```
① 开全局模式，选定一个节点（优先港/新/日，离内地近、时区近）
      ↓
② 确认 App 内 IP 与浏览器 IP 一致（ipinfo.io / ip.sb）
      ↓
③ 同一设备、同一 IP 走完：注册 → 上传证件 → 人脸 → 签署 → 提交
      ↓
④ 提交后保持不变，直到收到审核结果
      ↓
⑤ 拿到开户确认信、核对持牌法团名称后，再考虑是否切回直连
```

| ❌ 别做 | 原因 |
| --- | --- |
| App 用代理、浏览器用直连 | 出口 IP 不一致 |
| 手机开代理、电脑直连，交叉提交 | 同上 |
| 提交到一半切节点 | 中途 IP 跳变，直接进风控视野 |
| 频繁换节点 | ⚠️ **频繁切换比"一直用某个境外 IP"更可疑**——后者像正常用户，前者像在试探风控 |
| 断线重连后不确认 IP 是否变了 | 等于换了一次身份 |
| 一台设备同时挂多个地区节点 | 系统无法判断哪个是真身 |
| **借别人的网络环境/设备** | 资料与 IP 归属人不对应，等同于代持 |

**工具怎么挑**：要**专用客户端**（系统级代理/TUN，能覆盖 App 流量，不是只改浏览器）、支持**订阅导入**（切节点不用反复改配置）、**多端同订阅**（手机与电脑 IP 保持一致）。**🚫 不用免费节点**——流量可能被中间人监听。

---

## 六、🚫 红线清单

```
🚫 不要用境外网络把居住地址申报成"现居香港/海外"
🚫 不要在境外网络下申报非中国税务居民
🚫 不要使用来路不明的免费节点 / 公共代理（证件与验证码会泄露）
🚫 不要在多台设备、多地区同时登录同一券商账户
🚫 不要用 VPN 规避银行的反洗钱审查
🚫 不要用网络环境绕过平台的"人在当地"要求后仍作不实申报
```

**法律边界**：未经批准经营跨境专线/VPN 服务是**服务商的违法风险**，与使用者无关；个人使用非经营性跨境工具在实践中极少被追责但并非没风险。**真正的大风险是拿它伪造居住地/税务居民身份**——那是对金融机构的虚假陈述。
