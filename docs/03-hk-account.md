# 03 港股开户攻略

> 本章目标：从零开出一个能正常交易的香港证券账户，并知道账户里还能开哪些权限。
> 关联阅读：[02 行前准备](02-prepare.md) · [05 入金与出金](05-funding.md) · [06 券商对比](06-brokers.md)

---

<a id="hk-1-methods"></a>

## 1. 三种开户方式

### 1.1 方式一：亲临香港面签（最稳）

**谁用**：第一次开户、想开融资账户/期权权限、后续想用香港本地银行与本地提现。

**流程**：
1. 预约：券商官网/电话预约开户办事处（多数在香港九龙/上环/中环的办公楼）
2. 携证件赴港：港澳通行证 或 护照 + 住址证明原件 + 地址证明原件 + 地址证明原件
3. 现场：出示证件原件、出示住址证明原件、录影或签署风险披露文件、签署开户协议
4. 回传：券商远程处理，可能需要你在香港配合一次电话确认
5. 等待：1–3 个工作日出账户，可开通网银和交易密码

**耗时**：预约 + 赴港一趟 + 1–3 个工作日审核
**费用**：赴港交通住宿自付；开户本身多数免费

**优点**：通过率最高，能开全权限
**缺点**：要专程跑一趟香港

---

### 1.2 方式二：远程见证开户（近年主流）

**谁用**：无法专程赴港，但有香港住址证明，或券商提供内地见证点。

**两种子形式**：

| 子形式 | 说明 | 代表做法 |
| --- | --- | --- |
| **A. 视频见证** | 在线视频通话，核验证件原件 + 地址证明 | 多数香港互联网券商提供 |
| **B. 内地见证点** | 在内地某网点/办事处面签，文件寄香港 | 部分券商与内地银行/券商有合作网点 |

**核心材料**：
- 港澳通行证 或 护照
- **住址证明**：多数券商接受「内地地址证明」+ 额外条件；要求「香港住址证明」时需要能证明你在港有居住地址（租房合同 + 在港朋友的居住声明 + 部分场景需水电账单）
- 有时需要**香港身份证**（如果你是"新来港人士"，即持港澳通行证获发香港身份证的非永久居民，也能用香港身份证开户）

> ⚠️ **必须知道：这条路的政策窗口在收窄。**
> 港交所与香港证监会（SFC）对内地居民远程开户的合规要求持续加强。多个平台在 2023–2025 年间多次调整甚至暂停了"纯远程 + 内地地址"的路径，改为要求：
> - 赴港完成一次身份核实（现场或到港见证），或
> - 提供**真实香港居住地址证明**，或
> - 通过券商内地关联机构（如华泰证券的香港子公司在内地设点）办理
>
> **行动建议**：不要依据任何（包括本手册在内的）旧攻略直接提交。先联系券商客服，问三个问题：
> 1. "持中国内地身份证 + 港澳通行证，目前能否申请香港证券账户？"
> 2. "如果能，需要香港住址证明吗？需要本人到港吗？"
> 3. "如果需要到港，是去你的香港办事处还是内地见证点？"
>
> **务必让对方以邮件/工单形式书面回复并留存**，将来若有纠纷这是凭证。

---

### 1.3 方式三：通过内地关联渠道（最省心）

**谁用**：本来就用内地券商，希望一个 App 管理港美股。

**代表**：
- **华泰证券（内地）→ 华泰国际（香港）**：内地华泰 App 内申请香港账户，走"见证开户"，用内地华泰的港币通账户结算
- **中信证券（内地）→ 中信里昂证券**：类似
- **国泰海通（内地）→ 香港子公司**

**优点**：一个 App、人民币或港币结算、客服中文、遇到问题有人对接
**缺点**：可选券商范围小、部分功能（比如窝轮）不在内地 App 内

<a id="hk-2-flow"></a>

## 2. 开户全流程

以一个典型的香港互联网券商为例：

```
第 1 步  注册账号
         邮箱 + 手机号，设置密码
         ↓
第 2 步  选择账户类型
         现金账户（Cash）/ 保证金账户（Margin）
         ↓
第 3 步  填写个人资料
         英文姓名（按护照/通行证拼音）
         国籍：中国  |  税务居民国：中国
         居住地址、通讯地址、税务地址
         职业、收入来源、净资产、预计入金规模
         ↓
第 4 步  上传证件
         身份证 / 港澳通行证 / 护照
         住址证明（近 3 个月）
         ↓
第 5 步  身份核实
         面签（香港办事处）/ 视频见证 / 内地见证点
         ↓
第 6 步  签署文件
         客户协议、风险披露、税务声明（W-8BEN 等）
         ↓
第 7 步  等待风控审核        1–10 个工作日
         ↓
第 8 步  开户成功
         收到账号信 → 首次登录 → 绑定银行账户
         ↓
第 9 步  入金               见第 05 章
         ↓
第 10 步 开通交易权限
         风险测评（融资账户需重做更严格版本）
```

### 2.1 填写资料的十个细节

| 字段 | 正确做法 | 常见错误 |
| --- | --- | --- |
| 英文姓名 | 严格照护照/通行证资料页的拼音，姓和名中间空格与护照一致 | 自己重新拼 |
| 税务居民国 | **China** | 填 Hong Kong（后果严重：会被按非协定税率预扣股息） |
| 是否美国税务居民 | No | 勾 Yes 会走 FATCA 复杂流程 |
| 是否可申请税收协定待遇 | **Yes**（中国在协定名单内） | No → 股息被预扣 30% |
| 国籍 | China | — |
| 居住地址 | 与住址证明**逐字一致** | 填一个"看起来更像香港"的地址 |
| 通讯地址 | 可与居住地址相同 | 填了无法收件的地址 |
| 职业 | 如实填写（工程师/教师/个体经营…） | 填"自由职业"但注明资产 500 万 |
| 收入来源 | 如实 | 夸大 |
| 首次入金金额 | 与你实际打算入金**接近** | 填 100 万但只入 1 万（触发反洗钱问询） |

### 2.2 税务相关表格

香港券商一般会要求签署：

| 表格 | 作用 |
| --- | --- |
| **W-8BEN** | 声明非美国税务居民身份（若你有美股权限） |
| **W-9** | 仅当你是美国税务居民时需要，你不是 |
| **自认证表格**（Self-Certification） | 券商代你向香港税务局声明非香港税务居民，避免被预扣股息税 |

> 💡 香港没有股息税/资本利得税，但**非香港税务居民**在港券商持股若券商无法确认你的税务居民身份，会按"未知税务居民"处理，**代扣税**。签好自认证表格可以避免这个麻烦。

<a id="hk-3-permissions"></a>

## 3. 交易权限与门槛

| 权限 | 门槛 | 说明 |
| --- | --- | --- |
| **港股现货（现金）** | 无（开户即可） | 买股票 |
| **港股融资（孖展 Margin）** | 现金账户常见默认给 2 倍；正式融资账户通常要求资产 ≥ **100 万港币**（或等值），或由券商个案审批 | 杠杆交易，风险成倍放大 |
| **新股认购（IPO）** | 一般无门槛（融资账户需满足券商规定市值/持仓） | 需在券商 App 里开通"新股认购"权限 |
| **暗盘交易** | 一般随 IPO 权限开放 | 上市前一日的场外交易 |
| **窝轮（Warrants）** | 需完成风险评估问卷 | 高风险产品 |
| **牛熊证（CBBC）** | 需完成风险评估问卷 | 可归零，高风险 |
| **期权（股票期权）** | 通常要求账户资产 ≥ **20 万港币** + 完成期权课程与测试 | 认购/认沽合约 |
| **期货** | 通常要求资产门槛 + 单独审批 | 杠杆极高 |
| **美股** | 视平台规则，部分要求账户资产门槛或先开通港股满一定时间 | 见 [04 美股开户](04-us-account.md) |

> ⚠️ **新手建议**：开户后**先只开现货**。等你真正理解杠杆、窝轮、强平的机制，再考虑开权限。见 [09 风险与避坑](09-risks.md)。

<a id="hk-4-vs-connect"></a>

## 4. 港股与港股通对比

这是最容易被问的问题，也是最容易选错的一步。

| 维度 | 港股通（内地券商） | 香港券商账户 |
| --- | --- | --- |
| 币种 | 人民币买卖，自动换汇 | 港币/美元 |
| 标的范围 | 恒生综合大/中/小型股指数成分股 + 部分 ETF | **全部港股**（约 2600 只）+ 窝轮牛熊证 |
| 能不能买仙股 | ❌ | ✅ |
| 能不能打新（IPO） | ❌ | ✅ |
| 融资杠杆 | 孖展 2 倍 | 2–4 倍 |
| 交易时间 | 9:30–16:00（与 A 股同步） | 9:30–16:00，另加 16:01–18:00 收盘竞价后交易、9:00–9:30 开市前时段 |
| 交易日历 | 跟随内地 + 香港假期 | 香港假期（内地也休市但港股开市的日子较多） |
| 交收 | T+2 可卖（资金 T+2 到账） | 现金账户 T+2，**部分券商支持 T+0 卖**（港股已支持 T+0 回转交易） |
| 股息税 | **扣 20%**（H 股红利税） | 香港一般不扣（税券未提交时可能预扣） |
| 印花税 | 卖出 0.1% | 卖出 0.1% |
| 出金回内地 | 卖出自动结算到 A 股账户 | 需主动汇回，耗时且受额度约束 |
| 门槛 | 50 万人民币 | 通常 1 万港币起 |
| 适合 | 大额、只要大盘股、怕麻烦 | 要打新/全市场/杠杆/美股 |

**一句话决策**：
- 你要买的票 **在港股通名单里**，且 **不做打新、不加杠杆、不买美股个股** → **港股通**。
- 任何一条不满足 → **香港券商账户**。

<a id="hk-5-maintenance"></a>

## 5. 账户维护与年费

| 项目 | 常见情况 |
| --- | --- |
| **账户年费/管理费** | 多数互联网券商对普通账户免收，但**低于某资产门槛（如 1 万港币）会收"最低余额费"**（常见 50–100 港币/年，部分按季收） |
| **休眠处理** | 长期无交易、余额不足的账户可能被标记为休眠或关闭。**每年登录一次、动一笔**即可 |
| **纸质对账单** | 多数已改为电子月结单，注意邮箱不要被判定为垃圾邮件 |
| **税务年度文件** | 每年初会收到上一年度的税务汇总（用于中国个税申报），**务必保存**，见 [08 税务与合规](08-tax-compliance.md) |
| **密码过期** | 交易密码 90 天、网银密码 180 天不换会失效，改密码是常规操作不是异常 |
| **公司行动（拆股/派息）** | 需要你主动确认是否参与，默认可能"不参与"导致损失 |

> 💡 **一个真实坑**：不少港股投资者在**派息日卖出股票**，导致当期股息不再归自己。港股**除净日（Ex-date）**前持有即享有股息，**不需要做任何操作**。但在美股，DRIP/股息再投资、自动卖出等设置容易踩坑，见 [10 FAQ](10-faq.md)。

## 6. 开户后的第一笔操作检查表

```
[ ] 登录成功，已收到账号信
[ ] 已设置登录密码 + 交易密码 + 双重验证（2FA）
[ ] 已绑定香港银行账户（同名）
[ ] 已完成首次入金并到账
[ ] 已完成风险测评（普通档）
[ ] 已开通"新股认购"权限（如果想打新）
[ ] 已设置条件单 / 止盈止损（如果券商支持）
[ ] 已设置账户通知（价格提醒、成交推送）
[ ] 确认佣金费率与最低收费（见第 07 章）
[ ] 确认股息派发方式（现金 / 再投资）
[ ] 已知晓"港股 T+2 交收、卖出资金 T+2 到账"
```
