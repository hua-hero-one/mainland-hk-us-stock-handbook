# 02 行前准备：证件与材料

> 本章目标：把手册读完后，你的桌面上应该有全套材料，而且知道每一样材料是怎么来的。
> 建议在真正提交开户申请前，本章从头过一遍。

---

<a id="prepare-1-documents"></a>

## 1. 证件清单

### 1.1 必带（三选二，几乎都需要）

| 证件 | 用途 | 注意事项 |
| --- | --- | --- |
| **中国大陆居民身份证** | 身份证明、CRS 税务居民认定 | 正反面彩色扫描/拍照，四角完整、无反光 |
| **港澳通行证（回乡证）** | 赴港开户、见证开户、香港银行开户的必备 | 注意有效期，**建议剩余有效期 ≥ 6 个月** |
| **护照（个人资料页）** | 境外券商 KYC、海外银行开户、美国券商几乎必需 | 必须有**至少一页空白页**；信息页要有钢印/机读码 |

> 💡 **"三选二"是行业惯例**：多数香港券商接受「港澳通行证 + 住址证明」或「护照 + 住址证明」两种组合，用于满足 SFC 对身份核实的双重要求。实际以券商要求为准。

### 1.2 强烈建议一起准备

| 材料 | 说明 |
| --- | --- |
| **手机号** | 需能接收**国际短信**（含区号格式，如 +86 138xxxx）。国内号码通常可以，但部分平台会拒收虚拟号 / 5 号段 / 接码平台号码 |
| **邮箱** | 建议用 **Gmail / Outlook** 等境外邮箱，境内 163/QQ 邮箱偶有被系统风控拦截验证码的情况 |
| **香港银行账户** | 见 [第 3 节](#prepare-3-hk-bank)，这是入金通道的核心 |
| **境外收款账户** | 美元账户 / 支持收电汇的账户（走路线 C 必备） |
| **第二联系人** | 部分券商会问"紧急联系人"，姓名、关系、电话 |
| **职业与收入信息** | 用于 KYC 风险评估，如实填写 |

<a id="prepare-2-address-proof"></a>

## 2. 住址证明（Address Proof）

这是**驳回率最高的一项**。境外券商和香港银行都要求提供"最近 3–6 个月内、由第三方机构出具、显示姓名 + 完整地址 + 日期"的证明文件。

### 2.1 可接受的类型（按接受度排序）

| ✅ 接受度高 | 说明 |
| --- | --- |
| **银行对账单 / 月结单** | 中英文对照最佳；需显示姓名、地址、账号、日期、银行业务章 |
| **水电燃气账单** | 银行代扣的更好；需显示地址、期间用量、日期 |
| **电信/宽带/有线电视账单** | 三大运营商均可 |
| **信用卡账单** | 部分银行可用 |
| **政府寄送的官方信件** | 税单、社保账单、公积金对账单 |
| **房屋租赁合同 + 房东身份证** | 部分券商接受，通常需附水电账单 |
| **网约车/外卖平台账单** | 滴滴账单在部分场景可用，接受度一般 |

<a id="prepare-2-2-get-proof"></a>

### 2.2 怎么拿到"合格的"住址证明

**情况 A：住址有英文/拼音**
- 最好办。直接去银行网点打印近 3 个月的月结单（英文版或中英对照版），带业务章。
- 大多数银行 App 也提供电子对账单 PDF 下载，选择"英文"或"国际版"。

**情况 B：住址只有中文**
- **方案 1**：向银行申请带英文地址的对账单。很多银行国际业务部门可以出。
- **方案 2**：去公证处做一份**居住地址公证**（Standard Chinese Notary Certification），再由翻译公司做**英文翻译**并加盖章。这条路最稳，费用约数百元。
- **方案 3**：用**国际包裹面单 / 快递账单**（DHL、FedEx 到账单，显示寄件地址 = 你的中文地址 + 英文国家名），部分券商接受。
- **方案 4**：如果你是租房的，用租赁合同 + 房东配合出具居住声明。

> 🔍 **关键细节**：
> - 文件上的**姓名必须与身份证/护照完全一致**（拼音顺序也要一致）。
> - 地址必须**完整到门牌号 + 房间号 + 城市 + 省 + 邮政编码**，只写"XX市XX区"不行。
> - 账单日期要在**最近 3 个月**内（部分券商放宽到 6 个月）。
> - 所有文件用**彩色扫描件 / 手机原图**，不要用手机内置滤镜压缩，不要截图（要整页）。

### 2.3 常见坑

| ❌ 错误做法 | 后果 |
| --- | --- |
| 用朋友/同事的地址 | 与身份不符，几乎必被拒；严重者被列入风险名单 |
| 用虚拟地址 / 邮箱地址服务 | 多数券商明确禁止，封号 |
| 用共享办公地址（WeWork 等） | 接受度极低 |
| 账单是电子发票截图 | 不是"账单"，不是地址证明 |
| 地址手写/打字自制 | 必被拒 |
| 只提供部分页面 | 缺页＝无效 |

## 3. 预开一个香港银行账户

**这是整条链路上最关键、也最容易卡住的一步。** 香港券商几乎都需要一个**同名的香港银行账户**作为资金中转（有的也接受内地同名卡直汇，但受限额与政策影响）。

### 3.1 "见证开户" 是什么

你不需要飞香港。在**内地**的中资银行网点办理，由该网点**见证**你签署开户文件，银行再把文件寄送香港分行开立账户。整个过程你只跑内地。

### 3.2 主要可办理的银行（常见名单）

| 银行 | 内地见证网点 | 大致要求 |
| --- | --- | --- |
| **中国银行香港（BOCHK）** | 内地中国银行各分行 | 港澳通行证 + 身份证 + 地址证明；常需存入门槛金额或已有内地中行账户 |
| **招商永隆（CMB Wing Lung）** | 内地招商银行部分网点 | 需内地招行账户；通常要求首次存入一定金额 |
| **工银亚洲（ICBC Asia）** | 内地工商银行部分网点 | 需内地工行账户 |
| **汇丰（HSBC）** | 内地汇丰网点 | 可在内地开通内地汇丰并同步申请香港账户（HSBC One 等） |
| **渣打（SCB）** | 内地渣打网点 | 需预约，网点有限 |
| **建行亚洲 / 东亚银行 / 大新银行 / 恒生等** | 部分支持内地见证或需亲临香港 | 以各行最新政策为准 |

> ⚠️ **各家政策、网点范围、存入门槛变动频繁。** 例如"首次存入门槛"常见为 1 万港币等值或"日均资产达标"，但各行差异很大且随时调整。办理前请直接联系目标银行的内地客服确认：**① 我这种情况能否办理；② 哪些网点有资格；③ 需要准备什么；④ 有无首次存入门槛；⑤ 多久能拿到卡。**

### 3.3 开通后立刻要做的

1. **开通网银/手机银行**（有卡不等于能转账，没有网银很难用）
2. **开通"跨境汇款/内地代理行"功能**（有些叫"汇出服务"）
3. **开通 FPS 转数快**（Fast Payment System，香港本地转账必备，见 [05](05-funding.md)）
4. **设置收款账户时选对用途**：向券商转账时用途选"证券投资 / Securities Investment"，别乱填
5. **确认能收到 SWIFT 电汇**：让银行开通并确认 SWIFT 代码、收款行地址

### 3.4 常见问题

**Q：只有内地银行卡，没有香港账户能开户吗？**
A：能开证券账户，但**入金会很麻烦**。部分香港券商支持内地同名卡直汇，但额度受限（常见单笔几千港币、单日/单年限额）、经常被拒，且政策随时变。强烈建议还是先开香港账户。

**Q：香港账户能用 5 年不交易吗？**
A：多数银行会做**不动户（dormant account）**处理：不扣钱，但账户功能受限（可能无法转账/网银受限）。**每年至少动一次**（转一笔小钱进去或提一笔出来），或者主动联系银行说明情况。长期不动户可能被销户。

**Q：内地居民在港开银行账户，港币/人民币存哪个好？**
A：**港币**。多数香港券商只收港币或美元，用港币中转可少一次换汇损耗。详见 [05.5 换汇成本](05-funding.md#funding-5-fx-cost)。

<a id="prepare-4-network"></a>

## 4. 网络与设备

| 项目 | 建议 |
| --- | --- |
| **IP 归属地** | 部分券商在内地 IP 下会直接限制开户或加强审核。**不是必须用境外 IP**，但如果反复被拒，换一个网络环境再试有时有效。**不要用 VPN 反复切换 IP**，反而触发风控 |
| **浏览器** | Chrome 最新版最佳；避免隐私/反追踪插件（可能拦截上传脚本） |
| **手机** | 一部独立的、常用手机最佳。券商 App 与 App Store/Google Play 区域有关 |
| **拍摄证件** | 原图、自然光、无滤镜、无反光、无边框 |
| **App 来源** | 只从官网/官方应用商店下载，**不要装第三方"分身版"或"改区版"**，会被检测并影响提现 |
| **双备份** | 建议备用手机号 + 备用邮箱，避免验证码收不到导致账户被锁 |

<a id="prepare-5-rejections"></a>

## 5. 最常见的驳回原因

按出现频率排序：

| 排名 | 原因 | 解决办法 |
| --- | --- | --- |
| 1 | **住址证明不合格**（缺页、无日期、姓名不匹配、只有中文） | 见 [2.2](#prepare-2-2-get-proof) |
| 2 | **文件不清晰**（反光、模糊、像素过低、截图） | 自然光重拍或彩色扫描，300dpi 以上 |
| 3 | **姓名拼写不一致**（护照拼音 vs 银行对账单） | 严格按护照机读区（MRZ）拼写 |
| 4 | **地址与申请表不一致**（填了另一个地址） | 申请表的"居住地址"必须与证明文件一致 |
| 5 | **使用虚拟号/一次性邮箱** | 用真实手机号 + 常用邮箱 |
| 6 | **同名香港银行账户开户失败/被拒** | 联系银行问清楚原因，可能缺某份材料 |
| 7 | **风险测评结果与资金规模不匹配** | 如实填写，不要夸大 |
| 8 | **提交了 P 过的证件** | 会被永久拉黑 |
| 9 | **网络/IP 环境异常**（频繁切换国家） | 稳定在一个网络环境完成整个流程 |
| 10 | **身份重叠**（已有被封禁账户） | 换券商 |

> 💡 **驳回后能补件重提。** 收到拒信先别换券商，看清具体原因，补齐材料重新提交通常只多花 1–3 天。换券商反而要从零开始。
