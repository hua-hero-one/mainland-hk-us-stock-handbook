# 07 费用拆解

> 本章目标：知道每一笔交易真正付出多少成本，而不是只看"佣金万几"。
> ⚠️ 规费与费率随监管调整。**本文数字为编写时的量级参考，务必以港交所/纳斯达克官网与券商最新费率表为准。**

## 7.1 港股单笔成本拆解

### 7.1.1 成本项清单

| 项目 | 方向 | 大致水平 | 备注 |
| --- | --- | --- | --- |
| **券商佣金** | 买 + 卖 | 常见 0.025%–0.1%，极低至万 2.5 | 通常有单笔最低收费（常见 50 港币） |
| **平台费 / 使用费** | 每笔/每月 | 0–50 港币/笔，或按月收 | 注意"每个市场"重复收取 |
| **印花税（Stamp Duty）** | **仅卖出** | **0.1%** | 2023-08-28 由 0.13% 下调至 0.1% |
| **交易征费（SFC Transaction Levy）** | 买 + 卖 | 0.0027% | 香港证监会征收 |
| **交易费（HKEX Trading Fee）** | 买 + 卖 | 约 0.00565% | 港交所收取 |
| **交易系统使用费（TSUF）** | 买 + 卖 | 约 0.002% | — |
| **股份交收费（Settlement Fee）** | 买 + 卖 | 约 0.002% | — |
| **证监会交易征费 + 财汇局征费** | 买 + 卖 | 约 0.00015% + 0.00015% | 极小 |
| **结算所持股费（CCASS）** | 按持仓 | 持仓市值 × 约 0.005%（常见 0.002%–0.005%，最低若干） | 持有就有成本，别忘 |
| **换汇成本** | CNY→HKD | 0.1%–0.5% | 只在换汇时发生一次 |
| **电汇/入金费** | 每笔 | ¥50–150 + $15–25 | 只在出入金时发生 |

### 7.1.2 一边倒的结论

**港股买卖成本 ≈ 0.25%–0.35%（佣金 + 全部规费），其中印花税 0.1% 占大头，且只在卖出时收。**

大致结构：
```
买入成本 ≈ 佣金 + 平台费 + (0.0027% + 0.00565% + 0.002% + 0.002% + 0.0003%) ≈ 佣金 + 0.0107%
卖出成本 ≈ 买入成本 + 0.1% 印花税
```

### 7.1.3 算例

**买入 10 万港币腾讯（假设成交价 400 港币，250 股）**

| 项目 | 金额 |
| --- | --- |
| 成交金额 | 100,000.00 |
| 佣金（万 3，最低 50 港币 → 取 30） | 30.00 |
| 平台费 | 0.00 |
| 交易征费 0.0027% | 2.70 |
| 交易费 0.00565% | 5.65 |
| 交易系统使用费 0.002% | 2.00 |
| 股份交收费 0.002% | 2.00 |
| 证监会/财汇局征费 | 0.30 |
| **买入总费用** | **≈ 42.65 港币（0.043%）** |

**同价位卖出**

| 项目 | 金额 |
| --- | --- |
| 成交金额 | 100,000.00 |
| 佣金 | 30.00 |
| 印花税 0.1% | 100.00 |
| 其他规费 | ≈ 10.65 |
| **卖出总费用** | **≈ 140.65 港币（0.141%）** |

**一次完整买卖（买入 + 卖出）总成本 ≈ 183 港币 = 0.183%**，其中印花税占 55%。

### 7.1.4 港股通 vs 港股券商的成本对比（同样 10 万港币）

| | 港股通 | 香港券商（万 3） |
| --- | --- | --- |
| 佣金 | 约 0.025%–0.03%（常见最低 5 元人民币） | 0.03%（最低 50 港币） |
| 印花税 0.1% | ✅ 收 | ✅ 收 |
| 其他规费 | ✅ 收 | ✅ 收 |
| **平台费** | 一般 0 | 0–50 港币 |
| **股息税** | **20%（H 股）** | **0%（香港一般不征）** |
| 出金成本 | 0（自动结算回 A 股账户） | 换汇 + 电汇 + 结汇 |

**关键差异在股息税**：
- 持有市值 100 万港币、股息率 4% → 年股息 4 万港币
- 港股通：扣 20% = 0.8 万港币
- 香港券商：不扣 = 0
- **但**：港股通卖出后资金直接回人民币账户（零成本）；香港券商要卖出→换汇→电汇→结汇，成本可能 1%–2% 且要花 3–5 天

**结论**：
- **低股息、高换手、大额** → 港股通更划算（且资金不出境）
- **高股息、低换手** → 香港券商省 20%（但要算上资金回流的成本）

## 7.2 美股单笔成本拆解

### 7.2.1 成本项清单

| 项目 | 方向 | 大致水平 | 备注 |
| --- | --- | --- | --- |
| **佣金** | 买 + 卖 | **$0**（多数互联网券商 / IBKR L1） | 有最低收费（常见 $0.01–$3） |
| **SEC Fee** | **仅卖出** | 约 $0.000166/股，最低 $0.01，最高 $8.30 | 2025 年费率曾调整，以最新为准 |
| **FINRA TAF** | **仅卖出** | 约 $0.000166/股，最高 $8.30 | 券商代收代缴 |
| **ORF（OCC Clearing Fee）** | **仅卖出** | 约 $0.000166/股，最低 $0.01，最高 $8.30 | 清算费 |
| **其他规费（如 FINRA 会员费分摊）** | 卖出 | 每股几美分以内 | 通常合并显示 |
| **股息预扣税** | 自动 | **10%**（中美协定，需 W-8BEN） | **不是券商费用，但必须算进总成本** |
| **换汇（CNY→USD）** | 每次 | 0.15%–0.5% | 一次性或分次 |
| **提现费** | 每次 | $10–$25（电汇） | — |
| **入金电汇费** | 每次 | ¥50–150 + $15–25（中转行） | — |

> ⚠️ **规费是"卖出才收"**，很多人在算成本时漏掉。用美股做频繁交易的人，规费占比可能超过你的想象。

### 7.2.2 算例

**买入 100 股 VOO（单价 $500，成交额 $50,000）**

| 项目 | 金额 |
| --- | --- |
| 成交金额 | $50,000.00 |
| 佣金 | $0 |
| **买入总费用** | **$0（加换汇另计）** |

**同价位卖出 100 股**

| 项目 | 金额 |
| --- | --- |
| 成交金额 | $50,000.00 |
| 佣金 | $0 |
| SEC Fee（约 $0.000166/股） | $0.017（最低 $0.01） |
| FINRA TAF | $0.017 |
| ORF | $0.017 |
| **卖出总费用** | **≈ $0.05** |

**结论**：美股卖出的固定成本极低（$0.05）。**成本几乎全部来自换汇和股息预扣。**

### 7.2.3 美股的成本模型

```
持有美股的总成本 ≈ 换汇率差(一次性) + 卖出时 0.001%+ 规费 + 股息预扣 10%
```

| 场景 | 换汇成本 | 股息税(年) | 卖出规费 | 合计感受 |
| --- | --- | --- | --- | --- |
| 10 万人民币，长期持有 VOO（年股息率 1.3%） | 约 ¥300–500 一次性 | 约 $170/年 | ~$0.05 | 极低 |
| 10 万人民币，长期持有 SCHD（年股息率 3.5%） | 同上 | 约 $460/年 | ~$0.05 | 仍远低于港股通的 20% |
| 5 万人民币，年交易 50 次 | — | — | 每次 ~$0.05 | 规费可忽略 |

> 💡 **对照**：如果同样的钱买港股通的高息股（20% 股息税），10 万人民币持仓、4% 股息率，年股息 4000 元 → 税 800 元。换成美股 SCHD（约 3.5%），同样金额年股息约 $460 → 税 $46 ≈ 330 元。**省下的 470 元，接近美股一整年的股息率差异**。

## 7.3 最低收费陷阱

这是小资金投资者最常踩的坑。

### 7.3.1 陷阱原理

券商宣传"万 2.5"，听起来很有吸引力。但他们通常同时设一条：

> **最低收费：每笔最低收取 X 元/港元/美元。**

例：某港股券商佣金万 2.5，最低 50 港币。
- 买 10,000 港币 → 名义佣金 2.5 港币 → 实际收 50 港币 = **0.5%**
- 买 100,000 港币 → 名义佣金 25 港币 → 实际收 50 港币 = **0.05%**
- 买 1,000,000 港币 → 名义佣金 250 港币 → 收 250 港币 = **0.025%** ✅

### 7.3.2 换算成"盈亏平衡点"

| 佣金率 | 最低收费 | 达到名义费率所需交易额 |
| --- | --- | --- |
| 万 2.5 | 50 港币 | **200,000 港币** |
| 万 3 | 50 港币 | 166,667 港币 |
| 万 5 | 50 港币 | 100,000 港币 |
| 0.1% | 50 港币 | 50,000 港币 |
| 0.1% | 100 港币 | 100,000 港币 |

**美股同理**：$0 佣金但最低 $1/单 → 单笔 $500 的交易，成本 0.2%；单笔 $5,000 → 0.02%。

### 7.3.3 应对策略

| 策略 | 说明 |
| --- | --- |
| **拆单** | 把 1 笔 10 万的买入拆成 10 笔 1 万。**但要小心**：拆分后每笔的最低收费会累计，效果可能更差。**必须先算** |
| **降低频率** | 提高单笔金额，减少总笔数 |
| **谈费率** | 资金量大直接找客户经理谈免最低收费或降低门槛 |
| **选无最低收费的** | 部分券商佣金 0 但无最低收费（IBKR 有最低但按比例） |
| **别为省 50 港币而多交易** | 频繁交易的隐性成本（汇率、点差、情绪）远大于最低收费 |

> 💡 **反向陷阱**：有些小资金投资者为了"摊薄最低收费"而频繁交易，结果总成本更高。**先算总成本，再决定交易频率。**

### 7.3.4 一个真实算例

**场景**：本金 5 万港币，计划分 5 次买入，每次 1 万。

| 方案 | 笔数 | 名义佣金(万2.5) | 最低收费后 | 占交易额 |
| --- | --- | --- | --- | --- |
| A：5 笔各 1 万 | 5 | 12.5 港币 | **250 港币** | 0.50% |
| B：1 笔 5 万 | 1 | 125 港币 | **125 港币** | 0.25% |
| C：3 笔（2万/1.5万/1.5万） | 3 | 125 港币 | **150 港币** | 0.30% |

**结论**：**在这个金额区间，"少交易"比"拆单"更省钱。** 拆单只在单笔金额已远超盈亏平衡点时才有意义（此时拆单是为了减少单笔价格风险，不是为了省佣金）。

## 7.4 真实算例：三套方案对比

**场景**：10 万人民币，做 2 年长期持有，买港股 + 美股 ETF，每季度调仓一次（共 8 次买卖往返）。

### 方案 A：全部走港股通

| 项目 | 金额 |
| --- | --- |
| 买入 10 万港币（汇率折算，港币≈人民币 0.92） | 约 108,700 港币 |
| 买入成本（佣金 0.025% + 规费 0.0107%） | ≈ 39 港币 |
| 卖出成本（含 0.1% 印花税） | ≈ 148 港币 |
| 全年股息（假设 4% 收益率） | 4,348 港币 → 税 20% = 870 港币 |
| 2 年总成本 | **≈ 1,110 港币 ≈ 1,020 人民币** |

### 方案 B：全部走美股（IBKR）

| 项目 | 金额 |
| --- | --- |
| 购汇 10 万人民币 → $13,900（点差 0.3%） | 成本 ≈ 300 人民币 |
| 买入（$0 佣金） | $0 |
| 卖出（8 次，规费可忽略） | < $1 |
| 2 年股息（约 1.3% 收益率 × 2 年，10% 预扣） | 约 $360 → 税 $36 ≈ 260 人民币 |
| **2 年总成本** | **≈ 560 人民币** |

### 方案 C：混合（港股通 70% + 美股 30%）

| 项目 | 金额 |
| --- | --- |
| 港股通部分成本（按 70% 折算） | ≈ 714 人民币 |
| 美股部分成本（按 30% 折算） | ≈ 168 人民币 |
| **2 年总成本** | **≈ 880 人民币** |

**观察**：
1. 美股方案 2 年成本约 560 元，港股通约 1,020 元，**差 460 元**（占本金 0.46%）
2. 美股方案的优势**主要来自免 20% 股息税**，不是佣金
3. 换汇点差是美股方案最大的一笔（300 元 / 一次），所以**别频繁小额换汇**
4. 若持有期拉到 5 年，港股通的股息税劣势会被放大到 2,175 元 vs 美股 650 元

> ⚠️ **但要记住**：方案 B 的成本数字**不含**资金回内地的成本，也**不含**你为了合规投入的时间与不确定性。**这不是纯财务计算，是风险与成本的权衡。**

## 7.5 成本优化清单

```
[ ] 已拿到完整费率表（不只是佣金率）
[ ] 已确认单笔最低收费金额
[ ] 已确认是否有平台费/最低资产费（多少以下要收费）
[ ] 已确认换汇点差与是否有最低换汇费
[ ] 已确认电汇费用（发汇行 + 中转行 + 收款行）
[ ] 已确认提现费用
[ ] 已确认 W-8BEN 已生效（股息 10% 而非 30%）
[ ] 已把购汇集中到年初一次完成（摊薄点差与电汇费）
[ ] 已直接用港币买港股（减少一次换汇）
[ ] 已避免为省最低收费而过度交易
[ ] 已用券商内置换汇（IBKR AutoConvert 等）与银行比价
[ ] 已设置账户通知，避免长期不登录导致休眠被收最低资产费
```
