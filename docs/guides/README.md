# 实战攻略集（单券商 / 单银行开户流程）

> 本目录把第三方（知乎）的一手实操经验，整理成与本手册体例一致、可直接执行的单点攻略。
> **每篇都标注了原文出处、整理时间，以及"以官方最新口径为准"的提醒。**

## 为什么要做这一层

手册 [01–12 章](../../README.md) 讲的是**通用逻辑**（怎么选路线、材料有什么、钱怎么走、什么不能碰）。
但真要动手时，你面对的是一家具体的银行或券商：**具体点哪个 App、填什么、按什么顺序、哪里会卡住**。

这一层就是补上这块。特点：

- ✅ **逐步可执行**：按顺序做就行，标注了每一步的坑
- ⚠️ **时效性强**：银行与券商的开户政策一两年一变，**每次动手前先核对**
- 🚫 **保留红线**：原文里少数"走捷径"的做法（如向银行申报与实际用途不符的汇款理由），在本手册框架下被明确标注出来

## ⚠️ 使用本目录前必须知道

### 1. 原文都是"经验分享"，不是官方流程

所有攻略均整理自第三方作者的实操记录。**银行和券商的政策、额度、费率随时可能调整**，请以以下渠道的最新公示为准：

- 香港金融管理局（发牌与监管） <https://www.hkma.gov.hk/>
- 香港证监会公众登记册（查券商牌照） <https://apps.sfc.hk/publicregWeb/>
- 各银行/券商官网的费率表与开户须知

### 2. 原文中的推荐码 / 邀请链接

部分攻略保留了原文的**推荐码与推广链接**（如致富证券 PromoCode、ZA Bank 邀请码、WeLab 推荐码等）。这些属于原推广机制，**读者可自行决定是否使用**，也建议：

- 自行到官网核对当前活动（活动常有期限与条件）
- 不要把"有邀请码"当作判断某家券商是否合规的依据
- 本手册不对任何一家券商或银行做推荐或背书

### 3. 本目录不改变主手册的合规底线

无论哪家券商、哪家银行，以下红线不因任何攻略而改变（见 [08 税务与合规](../08-tax-compliance.md)）：

```
🚫 不分拆购汇、不借用他人额度
🚫 不使用地下钱庄、虚拟货币、个人代汇
🚫 不借用他人证券账户、不做代客理财分成
🚫 不伪造证件或地址证明
🚫 不向银行申报与实际用途不符的汇款理由  ← 本目录有 2 处原文踩到，已标注
```

### 4. 港卡 ≠ 境外券商账户

香港银行账户解决的是**资金通道**，不是**交易权限**。两者要分别办理，详见 [01 总览](../01-overview.md)。
