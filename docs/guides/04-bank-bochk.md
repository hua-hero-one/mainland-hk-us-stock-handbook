## ⚠️ 阅读前必读

1. **必须身处香港 + 连接香港本地 Wi-Fi**。原文明确：**严禁使用内地手机卡的数据漫游流量**，否则申请无法继续。
2. 中银香港的开户与转账额度规则会调整，尤其是**额度提升的时点**（原文为"第 4 天"），请以 App 内实际显示为准。
3. 内地中行与中银香港同名账户互转免手续费——**这是选它的核心理由**。

| 优势 | 说明 |

| **内地中行同名互转免费** | 手续费与到账速度都最优，这是本手册 [05 入金路径图](../05-funding.md#52-入金路径图) 里最省钱的组合 |

## 二、开户前准备

### 三样核心文件

| # | 材料 | 要求 |
| --- | --- | --- |
| 1 | **内地居民身份证** | 原件，有效期内 |
| 2 | **往来港澳通行证** | **有效期需超过 6 个月**，签注页有效 |
| 3 | **出入境记录** | 证明合法入境的关键文件 |

### 出入境记录怎么拿

1. 微信或支付宝搜索「**移民局 12367**」小程序
2. 选择查询「出入境记录」
3. 选择「**发送至邮箱**」
4. 收到**加密的 PDF**——这个文件就是银行认可的有效证明

> 💡 也可以在 [05 恒生](05-bank-hang-seng.md) 里提到的路径直接下载 PDF。

### 关键操作环境

- ✅ **人在香港境内**
- ✅ **连接香港本地 Wi-Fi**（机场、高铁站、酒店、商场）
- 🚫 **禁止**内地手机卡漫游流量

## 三、线上开户五步

### 1️⃣ 下载与登录

- 在**连接香港 Wi-Fi** 的环境下，从应用商店搜索「**BOCHK**」或「中银香港」，下载**官方 App**
- 打开后点击首页显著的「**开立账户**」按钮

### 2️⃣ 信息确认与账户选择

| 选项 | 选择 | 说明 |
| --- | --- | --- |
| 证件类型 | 「**中华人民共和国居民身份证**」 | — |
| 账户声明 | 勾选「**我身处香港，现时未持有任何中银香港个人或联名账户**」 | 必须真实 |
| 开户方式 | 「**我不在分行**」 | 走线上通道 |
| 账户类型 | 建议「**自在理财**」 | 需维持 1 万港币综合理财总值，但**开户过程中无需立即存入** |

> 💡 "自在理财" 的 1 万港币是**持续维持**要求，不是开户门槛。资金紧张时先别急着存。

### 3️⃣ 材料上传与验证

- **依次上传**：出入境记录 PDF → 身份证正反面 → 港澳通行证正反面
- **人脸识别**：环境光线适宜、动作清晰
- **位置权限**：App 请求时**必须选择"允许"**，用于验证身处香港

### 4️⃣ 信息填写

| 字段 | 填法 | 提醒 |
| --- | --- | --- |
| 联系资料 | 内地手机号 + 常用邮箱 | 用于接收通知 |
| **现居地址** | 内地详细住址 | ⚠️ 这是**实体卡的邮寄地址**，**不能用邮政信箱、酒店、宾馆地址**，且要能收平邮 |
| 开户原因 | 「储蓄」「投资港股」「保险」等 | 按实际选 |

### 5️⃣ 提交与审核

- 核对信息后提交
- 界面显示「已接收指示」或「申请正在处理中」，并给出**参考编号**（截图保存）
- 审核通常 **1–3 个工作日**，期间保持通讯畅通

## 四、开户成功与激活

审核通过后会收到短信/邮件通知。

| 步骤 | 内容 |
| --- | --- |
| 设置用户名与登录密码 | 通常 9–12 位字符 |
| 设置流动保安编码 | 6 位数字 |
| 正常使用 | 查询、转账等 |

### 转账额度

| 阶段 | 额度 |
| --- | --- |
| 线上开户后**前 3 天** | **1 万港币/天** |
| **第 4 天起** | 自动上调至 **20 万港币/天** |
| 需要更高额度 | **亲临香港任意分行柜台**办签名手续，通常无需预约 |

## 五、常见问题

**Q：证件拍摄不通过怎么办？**
A：最常见原因是**反光或模糊**。光线均匀拍摄、避免反光、对焦清晰。

**Q：收到"未能符合尽职审查"怎么办？**
A：原文提到**姓名仅两个字的申请人较易触发风控**。建议**直接前往线下分行尝试办理**，而不是反复重试线上。这是经验观察——**不是让你改名**，而是换一条审核路径。

**Q：实体卡收不到怎么办？**
A：默认**平邮**寄送，无人电话通知，2–3 周寄出。留意填写地址的实体信箱；长时间未收到可咨询小区物业或当地邮局。

**Q：账户要一直留着吗？**
A：原文建议**至少两年内进行一次交易**保持活跃，避免闲置问题。余额长期为 0 也可能触发休眠处理。

**Q：额度怎么配合入金？**
A：你的实际操作顺序应该是：
```
内地中行购汇 → 内地中行同名互转中银香港（免费、快）
             → 中银香港本地转券商（FPS 快）
```
详见 [05 入金路径图](../05-funding.md#52-入金路径图) 与 [08 兴业电汇](08-transfer-swift.md)。

## 六、风险与合规提示

| 项 | 说明 |
| --- | --- |
| ✅ **1 万港币持续维持** | 自在理财账户的持续要求，余额不足会有影响 |
| ⚠️ **地址要能收平邮** | 地址写错导致卡片丢失，激活就卡住 |
| 🚫 **地址不要乱填** | 虚假地址 = 伪造材料，见 [08 税务与合规](../08-tax-compliance.md) |
| ✅ **保留对账单** | 每年结汇/报税都要用，见 [05 出金](../05-funding.md#54-出金回内地) |
