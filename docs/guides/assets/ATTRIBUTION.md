- 新增攻略时，配图请放进 `docs/guides/assets/<攻略 slug>/`，并在本文档登记来源。
- 引用他人截图时，**必须**注明原文标题与地址。
- 优先使用自己重拍的截图（注意遮盖卡号、账号、手机号等个人信息）。
