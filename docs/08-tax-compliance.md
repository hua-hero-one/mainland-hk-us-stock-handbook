# 08 税务与合规

> 本章目标：知道哪些是合法的、哪些是灰色的、哪些是红线；以及赚的钱要不要报税、怎么报。
> ⚠️ **本章不构成税务意见。** 各地税务机关口径可能不同，金额较大的情况请咨询执业税务师/律师。

---

<a id="tax-1-crs"></a>

## 1. CRS（共同申报准则）

### 1.1 是什么

**CRS（Common Reporting Standard）** 是全球自动交换税务居民金融账户信息的标准。基于它的 **BEPS（税基侵蚀与利润转移）项目** 让 100 多个司法辖区互相交换数据。

**对你意味着什么**：
> 你在境外券商开的账户、你名下的境外银行账户，**其余额和年度收入信息会被自动交换回中国税务机关**。

### 1.2 中国参与情况

- 中国已在 **2014 年**签署《非居民金融账户涉税信息尽职调查管理办法》（国家税务总局等四部门公告 2014 年第 27 号），并参与 CRS 框架。
- 香港也已实施 CRS，**香港券商会把你的账户信息报送香港税务局**；香港税务局按 CRS 安排与其他税务管辖区（含中国内地）交换。
- 美国不是 CRS 参与方，但美国券商（IBKR 等）会按美国法规（**FATCA**）向美国国税局（IRS）报送美国纳税人的信息；非美国纳税人的信息一般不主动报送，但**若你未来成为美国税务居民**，历史信息可能被追溯。

### 1.3 实际影响

**这不是"要不要报税"的问题，而是"能不能不报"的问题。**  CRS 解决的是信息可见性，不是税负本身。

| 现实 | 说明 |
| --- | --- |
| 境外账户信息**会**到税务机关 | 但"知道"不等于"每次都查" |
| 大额、频繁、可疑的换汇 | 会触发风险提示和问询 |
| 银行结汇时问询 | 这是最常见的触发点 |
| 港股通的股息扣税 | 券商代扣，你无感知 |
| 境外券商的股息 | 多数情况下由境外券商按当地规则代扣（香港一般不扣；美股按 10% 预扣） |

> 💡 **实操建议**：把每一年境外券商的**年度对账单 / 税务汇总文件**（很多平台叫 Tax Statement、Consolidated Report）下载归档。这是你的申报依据，也是应对银行/税务问询的第一手材料。

<a id="tax-2-china-residency"></a>

## 2. 中国税务居民与境外所得

### 2.1 你是不是中国税务居民

按《个人所得税法》第一条和实施条例，同时满足以下任一条件即为**居民个人**：

| 条件 | 说明 |
| --- | --- |
| 在中国境内有住所 | 因户籍、家庭、经济利益关系而在中国境内习惯性居住 |
| 无住所但一个纳税年度内在中国境内居住累计满 **183 天** | — |
| 无住所但居住累计满 183 天的年度，**连续 6 年**内累计居住满 183 天的，**仍为居民个人** | "六年rule" |

> 💡 **"六年规则"** 对长期在境外工作/旅居的中国公民很重要。如果你连续 6 年不回国，且当年居住不满 183 天，可能不再是居民个人，境外所得的纳税义务会变化。**但请以最新税法与主管税务机关口径为准。**

### 2.2 境外所得要报吗

依据财政部、国家税务总局《关于境外所得个人所得税管理公告》（财政部 税务总局公告 2020 年第 3 号）：

> 居民个人取得的境外所得，应当按照《个人所得税法》及其实施条例规定，**计入综合所得或经营所得**，适用 3%–45% 的超额累进税率，**并依照规定办理申报**。

**涉及的项目通常包括**：
- 境外股息、红利
- 境外利息
- 境外财产租赁所得
- 境外经营所得
- 境外转让财产所得（资本利得）

### 2.3 股票相关：实务现状

| 项目 | 境外券商（港/美股） | 港股通 |
| --- | --- | --- |
| **股息** | 境外券商按当地规则代扣（香港一般 0%，美股 10%） | 券商代扣 **20%**（H 股红利税） |
| **资本利得（卖出价差）** | 境外一般不代扣 | 券商代扣 **0%**（个人在港股通的资本利得，目前按 0% 处理） |
| **中国境内是否还要申报** | ⚠️ **存在争议，实际征管较弱** | 港股通部分，境内券商通常不代报个人所得税 |

> ⚠️ **必须诚实说明**：
> 1. **实践中**，通过境外券商持有的股票分红与资本利得，在中国境内基本没有实际征管案例，税务机关也很少主动追缴。
> 2. **但这不等于"合法不申报"**。法条要求居民个人申报境外所得，是否纳税、何时纳税，取决于主管税务机关的具体口径。
> 3. **我不建议你把"没被查"当作合规依据。** 如果金额较大（例如六位数以上）或交易频繁，咨询执业税务师。
> 4. **低额、长期、分散**的情况，风险很低。核心风险不在税务，而在**外汇合规**。

### 2.4 境外税收抵免

如果境外收益已在境外被扣税（如美股 10% 股息预扣），依《个人所得税法实施条例》第二十条及 2018 年第 13 号公告，可申请**境外所得税收抵免**，限额为境外所得依中国税法计算的应纳税额。

**实操**：这通常意味着中国居民持有美股，理论上可抵免美方已扣的 10% 预扣税，避免双重征税。但**实际申请需要完整凭证**：
- 境外券商的股息预扣税凭证（Form 1042-S 或平台的对账单）
- 境外完税证明
- 完税证明的中文翻译（部分地区要求）

### 2.5 申报操作

- 境外所得通过**自然人电子税务局（扣缴端）**申报，通常在次年 3 月 1 日至 6 月 30 日的汇算期
- 香港/境外券商的年度税务文件通常在**次年 1–3 月**发出，留意邮箱
- 无境外所得申报经验的人可以先咨询 **12366**（国家税务总局纳税服务热线）

<a id="tax-3-hk"></a>

## 3. 香港税务要点

| 项目 | 说明 |
| --- | --- |
| **股息税 / 利得税（标准税率）** | **0%** |
| **资本利得税** | 香港无资本利得税 |
| **薪俸税** | 仅对在香港受雇/居住的收入征收 |
| **非香港税务居民** | 一般无香港纳税义务（除在港有职业性收入等特定情形） |
| **谁来判断你是不是香港税务居民** | 券商无法自行判断 → 要求你签署**自认证表格（Self-Certification）** |

> ⚠️ **实操要点**：如果你**没有**签署自认证表格，香港券商可能按"未知税务居民"处理，**从你的股息中代扣税**（历史上有 15% 的预扣安排）。签署后一般可免除。**开户时务必把这一项签掉。**

> ⚠️ **另一个盲点**：从"经香港向内地汇款"的金额与频率，有时会被银行或税务系统当作一个信号。**大额、频繁、结构不合理的跨境汇款**比账户本身更引人注意。

<a id="tax-4-us"></a>

## 4. 美国税务要点

### 4.1 股息预扣

| 身份 | 税率 |
| --- | --- |
| 美国税务居民 | 自己申报 |
| 非美国税务居民，不申请协定 | **30%** |
| **中国税务居民，W-8BEN + 协定待遇** | **10%** ✅ |
| 香港税务居民 | 通常 30%（港美之间无股息协定） |

### 4.2 资本利得

| 情况 | 征税 |
| --- | --- |
| 持有超过 **183 天** 的非美国税务居民出售美股 | **不征美国税** |
| 持有不超过 183 天 | 净利得按 30% 征税（中美协定下若居民国也征税，可能失去协定优惠）→ **别做短线** |
| 美国来源的房地产等非公开交易资产 | 可能征税 |
| NIWITs（外国公司，但被视同美国来源） | 特殊规则，见 IRS Pub. 519 |

### 4.3 常见误区

| 误区 | 事实 |
| --- | --- |
| "在美股赚钱要交美国税" | ❌ 长期持有的资本利得一般不交 |
| "我在美国券商有账户就是美国税务居民" | ❌ 看的是税务居民身份，不是账户所在地 |
| "美国账户信息会给中国" | ⚠️ 一般不会（美国非 FATCA 参与方），但若你将来是美国税务居民则会被追溯 |
| "卖出美股要交 30% 所得税" | ❌ 那是 183 天规则下的短期情况 |

## 5. 外汇管理红线

### 5.1 合法范围

| 行为 | 是否合法 |
| --- | --- |
| 每年购汇等值 5 万美元以内，申报用途为"证券投资" | ✅ |
| 超过 5 万美元，提交**真实用途证明**（券商开户证明、对账单） | ✅ |
| 香港同名银行账户之间正常转账 | ✅ |
| 从境外汇入境内并结汇，申报为"证券投资收益" | ✅ |
| 在年度额度内给家人朋友换汇 | ⚠️ **借用他人额度属分拆逃汇** |

### 5.2 明确违规

| 行为 | 后果 |
| --- | --- |
| **分拆逃汇**（多笔拆分、借用他人额度、他人代汇） | 列入关注名单、限制外汇业务、要求说明资金来源、追缴违规购汇 |
| **使用地下钱庄 / 换汇中介** | 可能涉及非法经营、洗钱；资金极易被冻结；个人账户被牵连止付 |
| **支付宝/微信/银行卡向个人换汇** | 违规网络购汇，涉刑风险最高 |
| **虚拟货币出入金** | 境内虚拟货币业务活动属非法金融活动；资金常混入诈骗资金 |
| **借用他人证券账户** | 违反券商协议与监管要求，账户被清退；严重者涉刑 |
| **伪造住址证明/伪造文件** | 券商永久黑名单；可能涉及伪造文件 |
| **"代客理财"收管理费** | 可能构成非法经营 |

### 5.3 银行风控会怎么看你

银行对个人购汇的监控逻辑（不完全公开，但通行）：

```
触发点：
  ├─ 短期内多笔、金额接近 5 万、汇往同一目的地
  ├─ 频繁购汇且金额接近年度额度上限
  ├─ 换汇后短期内汇出至境外账户
  ├─ 收汇方是个人账户而非持牌金融机构
  └─ 与"高风险名单"有交叉

后果：
  ├─ 电话问询用途
  ├─ 要求补充材料
  ├─ 降额或暂停
  ├─ 列入关注名单
  └─ 严重：纳入"名单"管理，2 年内不享受便利化额度
```

> 💡 **降低触发概率的三个动作**：
> 1. **年初一次性汇足**，不要分月分次。
> 2. **保留完整证据链**（购汇凭证 + 电票 + 券商对账单 + 成交记录）。
> 3. **如实回答用途**，说"境外证券投资"不是"旅游"。**撒谎的风险远大于说实话。**

## 6. 监管红线与举报渠道

### 6.1 券商端的风险，与你的关系

境外券商未经中国证监会许可向中国境内居民展业，在监管上被认定为违规。**但这主要是券商的责任，不等于投资者个人的投资行为违法。**

**但你需要注意**：
- 若你协助境外券商在境内招揽客户（介绍客户、收取返佣、代理开户），**你可能被认定为协助非法经营**
- 若你使用**他人账户**、**代他人操作并分成**，风险显著上升
- 若你使用**地下钱庄**，风险最高

### 6.2 遇到问题的正规渠道

| 事项 | 渠道 |
| --- | --- |
| 券商违规展业、虚假宣传 | **中国证监会 12386** 热线 / 证监会官网举报 |
| 外汇违规、异常冻结 | **国家外汇管理局** 各地分局；银行合规部门 |
| 税务问题 | **12366**（国家税务总局） |
| 券商纠纷 | 先找券商**合规/投诉部门**，再找 **SFC（香港证监会）**；美国券商找 **FINRA** 争议仲裁 |
| 诈骗 | **110**；涉外汇诈骗同时报 **国家外汇管理局** |
| 香港券商投诉 | **SFC 投诉热线 / e-Submission**；香港廉政公署（若涉贪腐） |

### 6.3 保留证据

无论是否发生问题，**保留**：
- 开户全程的邮件、聊天记录、工单截图
- 费率表、协议版本（带日期）
- 对账单、成交记录、税务文件
- 汇款凭证

**这些既是应对银行/税务问询的材料，也是万一券商出问题时的证据。**

---

## 7. 一句话总结四个"不要"

```
🚫 不要分拆购汇 / 借用他人额度
🚫 不要使用地下钱庄、虚拟货币、个人代汇
🚫 不要借用他人账户或做代客理财分成
🚫 不要伪造任何证件或地址证明

✅ 资金只走"本人银行账户 → 本人境外账户 → 本人券商账户"
✅ 用途如实申报，凭证完整保存
✅ 金额较大时咨询执业税务师/律师
```
