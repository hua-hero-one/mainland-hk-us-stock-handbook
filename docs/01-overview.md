# 01 总览：三条路线怎么选

> 本章目标：看完这一章，你脑子里应该有一张完整的地图，知道自己该走哪条路、每条路要多久要花多少钱。

## 0. 先纠正三个常见误解

**误解一："开通港美股账户" 是一件事。**
其实是三件独立的事：① 在券商开一个证券账户；② 让钱合法地从内地出去；③ 让钱（或盈利）合法地回来。很多人卡在第 ② 步。

**误解二："能买到美股" 就等于 "有美股账户"。**
港股通可以买到部分美股 ETF（部分 QDII 基金），但那是境内基金公司的产品，不是你自己的美股券商账户。差别见 [第 4 节](03-hk-account.md#hk-4-vs-connect)。

**误解三："开户需要出境" 是绝对真理。**
港股账户过去确实必须亲临香港，但现在部分券商支持远程见证开户，条件是提供**在港住址证明**或**赴港面签**。具体支持范围各家不同、变动频繁，务必以券商开户前公示为准。

## 1. 三条路线总览

| 维度 | 🅰️ 内地券商港股通 | 🅱️ 香港券商账户 | 🅲️ 境外券商直接开户 |
| --- | --- | --- | --- |
| **能买什么** | 港股通标的（约 500+ 只） | 全部港股；部分平台附带美股 | 全部港股 + 全部美股 |
| **账户开在哪** | 内地券商 A 股账户 | 香港持牌券商（SFC 牌照） | 香港 / 新加坡 / 美国持牌券商 |
| **是否必须出境** | ❌ 不需要 | 多数需要赴港（远程或面签） | 不一定，取决于券商政策 |
| **核心证件** | 内地身份证 + 内地银行卡 + 风险测评 | 港澳通行证/护照 + 住址证明 + 银行账户 | 护照 + 住址证明 + W-8BEN |
| **入金难度** | ⭐ 人民币直接转入 | ⭐⭐⭐ 需先有香港银行账户 | ⭐⭐⭐⭐ 需境外资金通道 |
| **资金回内地** | ⭐ 卖出结算自动到 A 股账户 | ⭐⭐ 需从香港汇回 | ⭐⭐⭐ 难度最高 |
| **最小资金门槛** | 无（但 50 万门槛可开融资类） | 通常 1 万港币起 | 通常 100–1000 美元起 |
| **单笔成本量级** | 佣金 ~0.025% + 印花税 0.1% | 同左，另加平台费 | 佣金常为 0，但有监管规费 |
| **适合谁** | 只买港股、大额资金、怕麻烦 | 想买港股全市场 / 打新 / 融资 | 想买美股、熟悉境外规则 |
| **主要风险** | 标的受限、不能买美股个股 | 平台合规政策变动 | 出金难、平台被清退风险 |

<a id="route-a-hk-stock-connect"></a>

## 2. 路线 A：内地券商港股通

**做什么**：在你已有的内地 A 股账户里开通"港股通"业务权限。

**怎么开通**：
1. 在内地券商 App / 柜台找到"业务权限 → 港股通"（各券商叫法不同）
2. 完成风险测评（C1–C5，C4 风险承受能力一般即可）
3. 签署风险揭示书、开通第三方存管
4. 部分券商需要到营业部现场办理并做知识测试（"港股通业务知识测评"，80 分以上通过）

**门槛**：
- 证券账户资产 **≥ 50 万元人民币**（通常要求证券账户及资金账户内的资产合计）
- 需签订《港股通交易风险揭示书》
- 20 个交易日平均资产达标

**能做什么**：
- 买卖港股通标的（**只能在交易日 9:30–16:00 委托，且 T+0 交收但 T+1 可卖**）
- 部分标的可做**孖展（融资）**，杠杆 2 倍
- 通过跨境 ETF 间接持有美股/全球指数

**不能做什么**：
- 不能买港股通标的之外的股票（如很多小盘股、部分生物科技股）
- 不能买美股个股、不能打美股新股
- 不能参与港股 IPO 抽签（这是港股券商的独有优势）
- 单一标的有持股比例限制（一般不超过该股 10% 的公众持股量）

> 💡 港股通**分红要扣 20% 个人所得税**（H 股红利税），这一点常被忽略——详见 [07 费用拆解](07-fees.md#fees-1-hk)。

<a id="route-b-hk-broker"></a>

## 3. 路线 B：香港券商账户

**做什么**：直接在持牌香港券商（SFC 持牌）开一个真实的香港证券账户。

### 3.1 三种开户方式

| 方式 | 条件 | 适合 |
| --- | --- | --- |
| **① 亲临香港面签** | 本人持港澳通行证或护照赴港，在券商网点/办事处面签 | 最稳，一趟解决，后续可远程维护 |
| **② 远程见证开户** | 券商提供远程视频见证，多数仍需**香港住址证明**或本人曾赴港 | 已去过香港、或有亲属/同事在港可出具地址 |
| **③ 券商内地关联渠道** | 内地券商（华泰、中信等）在内地设点受理香港子公司账户 | 想用内地 App 一站式管理 |

> ⚠️ **政策变动频繁。** 港港证监会对"内地居民远程开户"的客户身份与资金来源审查持续收紧，部分券商已暂停对内地居民开放纯远程开户。请务必在办理前向券商客户经理确认最新准入政策，不要以一年前的攻略为准。

### 3.2 港股券商的独家优势

- **IPO 抽签（打新）**：港股 IPO 认购与暗盘交易，这是 A 股投资者完全没有的体验
- **全部港股标的**：包括仙股、老千股，也包括港股通买不到的中小盘
- **孖展（融资）**：港股券商普遍提供 2–4 倍杠杆（现金账户通常 1:2，融资账户最高 1:4 甚至更高，视乎资质）
- **窝轮/牛熊证**：高风险产品，务必先看 [09 风险](09-risks.md)
- **支持美股**：多数香港平台同时提供美股交易（同一账户、同一本港币结算），见下一节

<a id="route-c-offshore-broker"></a>

## 4. 路线 C：境外券商直接开户（主要为了美股）

**做什么**：在境外持牌券商（美国、新加坡、香港）开一个**以你本人为税务居民的中国大陆居民账户**。

**核心文件**：**W-8BEN**（Non-U.S. Person Certificate of Tax Residency），相当于境外版的"个税居民身份声明"。

**可接触的美股券商类型**：

| 类型 | 代表 | 大陆居民可开户性 | 备注 |
| --- | --- | --- | --- |
| **传统美国本土券商** | Schwab（盈透富达）、Fidelity（富达）、E\*TRADE、Firstrade | 多数接受非美国税务居民在线开户 | 出金必须走境外银行；盈透、富达支持较友好 |
| **中资背景平台** | 盈透证券（IBKR）、富途、老虎、长桥、华泰国际 | 相对友好，但政策频繁调整 | 盈透对大陆居民最"标准化" |
| **互联网券商** | Webull、eToro、TradeStation、Robinhood | 部分可用，部分限制非美国居民 | Robinhood 2024 年后基本不向非美国居民开放新账户 |
| **新加坡/东南亚平台** | 渣打、 DBS、盈透新加坡、moomoo 新加坡 | 需新加坡地址或受邀 | 门槛更高 |

### 美股开户的现实约束

1. **几乎都需要境外银行账户做资金中转**，或至少能接收电汇。
2. **地址必须自洽**：申请表上的地址、证件地址、水电账单地址、香港银行开户地址要能对上。
3. **提现回内地是最难的部分**，除非你本身有境外收入/合法境外资产可以"进出"。

> 📌 如果你的核心诉求是**长期持有宽基 ETF（如 VOO、QQQ、VTI）**，且不急着用钱，路线 C 的性价比（$0 佣金 + 10% 股息预扣）确实远优于一切 A 股方案。但请务必先读完 [08 税务与合规](08-tax-compliance.md) 和 [09 风险与避坑](09-risks.md)。

<a id="full-process-six-steps"></a>

## 5. 全流程六步

不管走哪条路线，完整流程都是这六步：

```
① 准备材料   身份证 / 港澳通行证 / 护照 / 住址证明 / 邮箱 / 手机号
      ↓
② 开境外银行账户   香港银行见证开户 或 已有境外账户（入金通道！）
      ↓
③ 开证券账户   线上申请 → 上传证件 → 见证/面签 → 风控审核（1–10 个工作日）
      ↓
④ 入金   内地购汇 → 电汇/FPS → 券商账户（1–3 个工作日）
      ↓
⑤ 交易   绑定交易密码 / 开通交易权限 / 设置止盈止损
      ↓
⑥ 出金与税务   券商卖出结算 → 境外银行 → 汇回内地 / 依法申报
```

**时间成本**（经验值，非承诺）：

| 环节 | 耗时 | 可并行 |
| --- | --- | --- |
| 准备住址证明 | 1–7 天 | — |
| 香港银行见证开户 | 1–3 次赴网点，5–15 个工作日 | ✅ 与券商开户并行 |
| 券商开户审核 | 1–10 个工作日 | ✅ 与银行开户并行 |
| 首次入金到账 | 1–3 个工作日 | — |
| **合计（走完 B/C）** | **约 3–6 周** | — |

> 💡 **强烈建议第 ②③ 步并行。** 香港银行见证开户是整条链路里最慢的一环，先约银行，同时线上提交券商申请。

## 6. 怎么选（决策树）

```
                    你想投什么？
                         │
        ┌────────────────┴────────────────┐
        │                                 │
   只想买港股                        想买美股个股/ETF
        │                                 │
        ├─ 只买主流大盘股？            ├─ 已有境外银行账户？
        │   → 路线 A（港股通）         │   → 路线 C 直接开美股
        │   最省事，人民币出入          │
        │                                 └─ 没有？
        └─ 要打新/小盘股/杠杆？            ├─ 有港币账户或能赴港？
            → 路线 B（香港券商）          │   → 路线 B（香港券商 + 美股）
                                          │
                                          └─ 都不行？
                                              → 先解决账户：
                                                ① 香港银行见证开户
                                                ② 走路线 A 港股通
                                                ③ 暂缓，或用境内 QDII
                                                   ETF 基金替代
```

### 决策清单（按优先级回答）

| 问题 | 答"是" → | 答"否" → |
| --- | --- | --- |
| 有 ≥50 万人民币可长期闲置？ | 港股通可用 | 港股通需 50 万门槛 |
| 会定期汇回内地吗？ | 优先香港券商 + 香港银行 | 出金会很难 |
| 需要美股（不只是 QDII 基金）？ | 必须路线 B 或 C | 港股通 + QDII 够用 |
| 能接受资金在境外至少 1–2 年？ | 路线 C 可行 | 慎选路线 C |
| 每月交易 10 次以内、金额小？ | 港股通 | 香港券商最低收费会咬人，见 [07.3](07-fees.md#fees-3-minimum) |
| 完全不懂境外资金合规？ | 先读 [08 税务与合规](08-tax-compliance.md) | — |
