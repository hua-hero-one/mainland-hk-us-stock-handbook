# 05 入金与出金通道

> 本章目标：搞清楚钱怎么合法地出去、怎么回来，每一步花多少、多久到账、限额多少。
> **这是整本手册最重要的章节。** 开户资料不合规可以补件，资金通道不合规可能冻卡。

---

<a id="funding-1-quota"></a>

## 5.1 购汇与年度便利化额度

### 5.1.1 基本规则

根据国家外汇管理局《个人外汇管理办法》及其实施细则：

| 概念 | 说明 |
| --- | --- |
| **年度便利化额度** | 每人每年 **等值 5 万美元** 的结汇/购汇便利化额度 |
| **性质** | 是**额度**，不是**限制**——超过额度不是违法，而是需要提供**真实、合规的用途证明**走"真实性审核" |
| **银行柜面审核材料** | 境外证券投资等用途通常需要提供：身份证明 + 证券公司的**开户证明/账户对账单**等 |
| **期限** | 按自然年度计算（1 月 1 日 – 12 月 31 日），额度按银行统一计算 |

### 5.1.2 几个高频误解

| 误解 | 事实 |
| --- | --- |
| "5 万美元是上限，超了违法" | ❌ 是**便利化额度**，不是上限。超过可凭证明材料办理 |
| "分多次转就能绕过" | ❌ **分拆逃汇是明确禁止的**（见 5.6） |
| "我用支付宝/微信转账换汇" | ❌ 属于**违规网络购汇**，涉刑风险最高的一类 |
| "我给亲戚的额度用" | ❌ 借用他人额度 = 分拆逃汇 |
| "5 万是购汇还是结汇" | 两者共用同一套年度额度 |

### 5.1.3 用途怎么写

在银行购汇/汇出时，**"用途"选"证券投资"或"境外证券投资"**。

> 💡 **技巧**：先开好境外券商账户，拿到**券商的开户确认信（Account Confirmation Letter）和对账单**，再去银行申请。银行看到真实材料，审核会快得多。反过来先购汇后开户，银行问"钱汇给谁"时你答不上来。

## 5.2 入金路径图

### 路径 ①【推荐】内地银行 → 香港同名账户 → 券商

```
内地银行账户
  │  ① 购汇（年度便利化额度内，年初一次性备足）
  │  ② 电汇 SWIFT（USD 或 HKD）
  ▼
香港同名银行账户（中银香港 / 汇丰 / 招永隆 / 工银亚洲 ...）
  │  ③ 本地转账（FPS 转数快 / 港币转账 / 支票）
  ▼
香港券商账户
```

**优点**：最合规、最普遍被接受、金额不限（受购汇额度约束）、出错可追溯
**缺点**：多一到两个中间环节，2–4 个工作日到账
**耗时**：电汇 1–3 个工作日 + 本地转账当天到几分钟

---

### 路径 ②【最快】香港银行见证开户 → 直接本地转账

如果你已经在香港开了银行账户（见 [02.3](02-prepare.md#prepare-3-hk-bank)）：
- 香港本地转账（FPS 转数快）**几乎实时到账**，且**免手续费**
- 这是日常小额补仓的最佳方式

---

### 路径 ③【美股】直接电汇到境外券商

```
内地银行
  │  购汇 USD
  │  电汇（SWIFT）→ 券商指定收款行
  ▼
IBKR / 其他境外券商
```

- 需要拿到券商提供的**电汇收款指引**（银行名称、SWIFT 代码、账号、地址）
- 首次入金 ≥ 券商门槛（常见 $100–$1,000）
- **必须从本人同名账户汇出**

---

### 路径 ④ 内地卡直汇券商

- 部分券商**接受内地银行卡**（招行、工行、中行、部分地方性银行）直汇
- **限额严格**（常见单笔几千港币、单日/单年限额），且随时可能取消
- **不建议依赖**：作为主通道风险太高

---

### 路径 ⑤ 通过香港券商的"跨行转账"服务

- 部分香港平台提供 **"汇入"/"跨行转账"** 服务，把钱从你的内地卡转到香港券商（本质是持牌支付机构的通道）
- 好处：方便、速度快
- 坏处：额度有限；本质仍是"跨境支付"，年度总额受外汇局额度管理；**务必确认是通过持牌机构而非个人换汇**

---

### 🚫 路径 ⑥ 绝对不要碰

| 方式 | 为什么违法 |
| --- | --- |
| **地下钱庄 / 换汇中介** | 涉刑。资金来源不明易被冻结，账户被牵连止付；当事人可能构成洗钱罪共犯或非法经营罪 |
| **虚拟货币 OTC 出金（USDT 等）** | 2021 年后中国境内虚拟货币相关业务活动属非法金融活动；个人参与兑换同样有法律风险，且资金常混入诈骗资金 |
| **借他人账户 / 借用他人购汇额度** | 分拆逃汇，且资金与他人混杂，牵连极大 |
| **"代客理财""配资"** | 可能构成非法经营，且本金不受任何保障 |
| **拆单绕过银行风控** | 触发银行反洗钱监测，后果严重 |

> 🚨 **一句话**：钱必须是"你从你自己的银行账户、按真实用途、经持牌机构"出去的。任何"帮你绕过监管"的中间人，代价都比你想的大得多。

<a id="funding-3-wire"></a>

## 5.3 跨境汇款实操

### 5.3.1 电汇（SWIFT）要素

| 要素 | 说明 |
| --- | --- |
| **汇款行** | 你在内地付款的银行 |
| **收款行** | 目的地的银行（银行电汇时通常自动填，你只填收款人信息） |
| **收款人姓名/账号** | 与你在目的地的账户完全一致 |
| **SWIFT/BIC** | 8 或 11 位代码，向你的银行索取 |
| **用途/附言** | 选"证券投资"，如券商有指定要求则照办。**不要写股票名称** |
| **汇款币种** | 决定你承担的换汇点差 |

### 5.3.2 成本构成

| 费用项 | 常见金额 | 备注 |
| --- | --- | --- |
| 发汇行手续费 | 常见 ¥50–¥150/笔 | 部分银行电子汇款更便宜（如手机银行"境外汇款"打折） |
| 购汇点差 | 见 [5.5](#funding-5-fx-cost) | **这是最大的一笔隐性成本** |
| 中转行费用 | 常见 $15–$25 | 收款行与发汇行不是同一家集团时可能扣 |
| 收款行费用 | $0–$25 | 汇款时可勾选"OUR"（对方承担）——但很多收款行不接受，实际由发汇行预扣 |
| 券商入账费 | 多数 $0 | 部分平台收 HKD 50–100 的"汇入费" |

**实操建议**：
- 用**大额一次性汇出**，把手续费摊薄。汇 5,000 美元，手续费占比远低于汇 500 美元
- 汇款附言保持简洁：`INVESTMENT` / `FUNDING` / 券商要求的话术
- 保留好**购汇凭证 + 电汇水单 + 券商对账单**，这三样是应对银行问询的完整链条

### 5.3.3 到账时效（经验值）

| 通道 | 时效 |
| --- | --- |
| 香港本地转账 / FPS | 秒级 – 几分钟 |
| 内地 → 香港电汇 | 1–3 个工作日 |
| 内地 → 美国电汇 | 1–3 个工作日 |
| 节假日 | 顺延；注意香港与内地假期不同 |

> 💡 **别在周五下午汇款。** 内地→香港电汇常遇周末顺延。

<a id="funding-4-withdrawal"></a>

## 5.4 出金回内地

### 5.4.1 三种情形

**情形 1：卖出盈利，留在境外继续投资**
→ 什么都不用做。这是境外券商账户的正常运作，也是最省事的方式。

**情形 2：卖出盈利，需要汇回内地使用**
→ 香港账户 → 内地银行结汇。可行，但：
- 受**个人年度结汇额度（等值 5 万美元）** 约束
- 超过额度需提供**真实性证明**（券商对账单、完税证明等）
- 银行会问用途，**如实回答"境外证券投资收益"**
- 需在银行"国际业务/外汇"柜台或手机银行办理**境外汇入 + 结汇**两步

**情形 3：境外券商 → 直接汇入内地银行卡**
→ 多数境外券商**不支持**，且内地银行收汇也常要求申报交易性质。

### 5.4.2 结汇实务

1. 收到境外汇入 → 银行做**涉外收入申报**（申报交易性质：证券投资收益 / 利润）
2. 汇入后需在**规定期限**内结汇（超出用途期限未结汇需说明）
3. 结汇时可**选择人民币或外币**
4. 个人年度结汇便利化额度：等值 5 万美元
5. 大额汇入可能被要求提交：
   - 境外券商的对账单 / 成交记录
   - 盈利计算说明
   - 完税证明（若已按 08 章申报）

> 💡 **提前准备**：在汇回前，先把境外券商的**年度对账单和成交明细**下载好。银行问的时候你能 3 秒内提供，比什么都强。

### 5.4.3 关于"钱回不来"的现实

很多人在这一环才发现自己被卡住。**请务必在开户前就规划好资金的下半场**：

| 你的资金主要来源 | 建议 |
| --- | --- |
| 境内工资/经营收入 | 购汇额度内出境，境外留存；回内地走结汇 + 证明 |
| 境外收入（工资、劳务） | 天然可以进出，但同样要申报 |
| 已有境外存量资产 | 最灵活 |

<a id="funding-5-fx-cost"></a>

## 5.5 换汇成本

### 5.5.1 三种换汇位置

| 换汇位置 | 典型点差 | 说明 |
| --- | --- | --- |
| **境内银行购汇** | 约 0.1%–0.5%（含点差与手续费） | 电汇时一次性完成，换汇+汇款一并 |
| **香港银行换汇** | 约 0.15%–0.6% | HKD↔USD 常见价差较窄 |
| **券商内置换汇（FX）** | 约 0.15%–0.5%（IBKR 较低） | 已在券商账户内的钱直接换；IBKR 自动按最优点差成交 |

> 💡 **IBKR 的 AutoConvert** 是很多人忽略的成本优化点：账户内 USD/HKD 不足时，系统按最优点差自动换汇，通常比在银行换更划算。

### 5.5.2 隐形换汇：出入金时的两次换汇

**经典陷阱**：内地购汇（CNY→USD，电汇）→ 香港银行收 USD → 换 HKD 入金券商（USD→HKD）→ 买港股（可能再换一次）。

**实际换汇次数可能是 2–3 次**，每次 0.2% 就是 0.4%–0.6%。

**优化方案**：
1. 购汇时**直接买港币（HKD）**而非美元，如果你的券商用港币结算 → 少一次换汇
2. 香港银行账户**同时开 HKD 和 USD 子账户**，买入什么币就汇什么币
3. 券商内有足够港币时，直接用港币买港股，**不换汇**

<a id="funding-6-limits"></a>

## 5.6 限额速查表

| 项目 | 常见限额 | 性质 |
| --- | --- | --- |
| 个人年度购汇便利化额度 | 等值 **$50,000** | 额度，非上限；超出需证明 |
| 个人年度结汇便利化额度 | 等值 **$50,000** | 同上 |
| 银行单笔电汇上限 | 常见 ¥50,000 或等值，**可申请提高** | 柜面可谈 |
| 香港券商单笔入金上限 | 常见等值 ¥50,000–¥500,000 | 部分平台无上限 |
| 内地卡直汇券商入金 | 常见单笔 ¥5,000–¥50,000 | 变动频繁 |
| 香港本地转账（FPS） | 无固定上限 | 受银行反洗钱监测 |
| 境外汇入内地 | 无固定上限 | 但受结汇额度与申报约束 |
| ⚠️ 分拆购汇 | **没有"额度"这回事——这是违法** | 见下 |

### 分拆逃汇（违规示例）

```
真实需求：汇 20 万美元
错误做法：找 4 个人，每人 5 万，分别汇
     ↓
问题：① 借用他人额度 = 分拆逃汇
     ② 资金来源解释不一致
     ③ 银行反洗钱系统会标记同 IP/同设备/同收款人
     ④ 后果：列入"关注名单"、限制外汇业务、要求说明、追缴
```

**正确做法**：直接去银行柜面，申请**超额真实性审核**，提交券商开户证明和对账单。这是合法通道，很多银行做过。

## 5.7 一张自检表

```
[ ] 已确认自己今年的购汇额度还剩多少
[ ] 已确认资金用途申报为"证券投资"
[ ] 已办理或规划好香港同名银行账户
[ ] 已拿到境外券商的电汇收款指引（SWIFT / 账号 / 地址）
[ ] 已保存好购汇凭证 + 电票 + 券商对账单
[ ] 已确认首次入金金额符合券商最低要求
[ ] 已算好汇率成本（点差 + 手续费 + 电讯费）
[ ] 已规划好出金路径（留存境外 or 结汇回国）
[ ] 已准备好应对银行问询的真实性证明
[ ] 确认未使用任何地下钱庄 / 代汇 / 虚拟货币出金
```
