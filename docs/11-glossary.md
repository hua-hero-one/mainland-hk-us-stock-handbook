# 11 术语表

> 按主题分组，中英对照。查找平台费率表、协议条款时，这些词最常出现。

---

## 账户与身份

| 缩写 / 术语 | 中文 | 说明 |
| --- | --- | --- |
| **KYC** | 了解你的客户 | 身份核实流程：证件、住址、自证、活体检测 |
| **AML / CFT** | 反洗钱 / 打击融资恐怖主义 | 资金来源审查 |
| **CDD** | 客户尽职调查 | KYC 的正式称谓 |
| **EDD** | 强化尽职调查 | 高风险客户（资金量大、来源复杂、高风险地区）会被要求更多材料 |
| **PEP** | 政治公众人物 | 政要及其近亲属，需额外审查 |
| **UBO** | 实际受益人 | 公司/信托背后的自然人 |
| **Suitability** | 适当性评估 | 券商评估你的投资经验与产品风险是否匹配 |
| **Risk Profile** | 风险测评 | 问卷形式，决定你能开什么权限 |
| **T+1 / T+2** | 交收日 | 成交后资金/证券交收的期限（美股 T+1，港股 T+2） |
| **Settlement** | 交收 | 钱与证券的最终交换 |
| **DVP** | 交收对付 | 资金与证券同时交付，降低对手方风险 |
| **CCASS** | 中央结算系统 | 香港的证券中央结算与存管系统 |
| **Nominee** | 名义持有人 | 券商以名义持有人身份持有你的股票（这是正常的） |
| **Beneficial Owner** | 受益所有人 | 最终实际享有资产的人 |
| **POA / Discretionary** | 全权委托 / 授权管理 | 你委托他人（含券商）代为投资 |

## 账户类型

| 术语 | 中文 | 说明 |
| --- | --- | --- |
| **Cash Account** | 现金账户 | 全额付款才能买，不能借钱 |
| **Margin Account** | 保证金账户 | 可借券商资金买（杠杆），有强平机制 |
| **Unrestricted Cash Account** | 无限额现金账户 | 券商不预扣部分结算金，但违规会被限制交易 |
| **IPO Subscription** | 新股认购 | 打新 |
| **DRIP** | 股息再投资 | 自动用股息买更多股票 |
| **Fractional Shares** | 碎股 | 允许买不足 1 股的美股（如 0.3 股 VOO） |
| **Paper Trading** | 模拟交易 | 不涉及真实资金 |
