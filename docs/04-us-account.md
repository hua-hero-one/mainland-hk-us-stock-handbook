# 04 美股开户攻略

> 本章目标：开出一个能正常交易美股、且不会因为税务表格填错而被多扣税的账户。
> 关联阅读：[03 港股开户](03-hk-account.md) · [05 入金与出金](05-funding.md) · [08 税务与合规](08-tax-compliance.md)

---

<a id="us-1-routes"></a>

## 1. 四条路线

### 1.1 路线 A：盈透证券（Interactive Brokers, IBKR）

**为什么把它放第一位**：对大陆居民最"标准化"——接受中国税务居民、接受 W-8BEN 在线填写、接受电汇入金、支持多币种、佣金低（美股按股数阶梯，$0 最低）、可同时交易美股/港股/全球 100+ 个市场。

**开户流程**：
1. 官网注册 → 选 Individual 账户 → 填税务居民信息
2. 提交 **W-8BEN**（在线，PDF 或电子签署）
3. 上传护照个人资料页 + 住址证明
4. 完成**税务问卷**（Tax Forms → Non-US Person → W-8BEN）
5. 通过 **Identity Verification**：证件自拍 + 活体检测 + 可能的人脸比对
6. **首次入金**：电汇 USD ≥ 100 美元（到账后账户激活）

**等待**：3–10 个工作日（视频核验排期可能更久）

**费用**：美股 L1 单笔 $0 佣金（月 10 万股以内），另有最低 $1/单或按比例；换汇汇率点差约 0.15%–0.25%（对大多人比银行划算）；出金电汇费按券商标准

**不足**：
- 出金**不支持直接汇到内地银行卡**（多数情况下），需要先到香港账户或可接收电汇的境外账户
- 港股交易体验一般，不如本地互联网券商
- 部分券商的"快速入金"中国内地通道此前可用，需在开户时确认当前政策

---

### 1.2 路线 B：中资背景平台（富途 / 老虎 / 长桥 / 华泰国际）

**特点**：中文界面、中文客服、App 体验好、港美股一体、部分支持内地手机号直接注册。

**关键门槛差异（各平台不同、频繁调整）**：

| 平台类型 | 常见准入要求 |
| --- | --- |
| **港股账户** | 内地居民常需：香港身份证 / 港澳通行证 + 香港住址证明 / 或赴港面签 |
| **美股账户** | 通常额外要求：① 已有该平台港股账户并满足**资产门槛**（常见 1 万–5 万港币）；② 或账户总资产达到某门槛；③ 或已通过"美股交易权限"的风险测评 |

> ⚠️ **重要**：这些平台的内地居民政策在 2023–2025 年间反复调整，常见变化包括：
> - 内地居民新开户需要先赴港完成身份核实
> - 美股权限需要满足"日均资产"或"已入金满 N 个月"
> - 收紧入金通道（如取消内地卡直汇）
>
> **开户前必须先问客服这四个问题**：
> 1. 内地身份证能否开户？现在还需要什么额外条件？
> 2. 美股权限的当前资产/时长门槛是什么？
> 3. 内地银行卡能否直接入金？限额多少？
> 4. 资金能否从券商提现到内地同名银行卡？

---

### 1.3 路线 C：美国本土传统券商（Schwab / Fidelity / E\*TRADE / Firstrade）

**适合**：已有美国身份、已有美国地址、或本身就打算长期在美生活的人。

**大陆居民的实际情况**：
- **盈透（IBKR）**：接受非美国税务居民，**可用境外地址 + 护照 + W-8BEN 在线开户**，这是最现实的选项
- **富达（Schwab）**：接受非美国税务居民在线开户，需填 W-8BEN，但**审核严格**，且部分情况要求额外材料
- **富达真达（Fidelity）**：在线申请非美国居民账户，审核较严，出金通常需 ACH 到美国账户
- **Firstrade / E\*TRADE**：多数接受非美国居民开户

**共同点**：
- 大多需要**境外银行账户**做 ACH/电汇入金
- 出金一般需要**能够接收 ACH 或国际电汇**的账户
- 有的还要求"实际居住地"证明与 IP 一致

---

### 1.4 路线 D：赴美/赴港开立美国本土账户

- **赴美**：需旅游/商务签证 → 现场开立 Schwab / Fidelity → 需美国地址（部分券商接受国际地址 + 护照）
- **赴港**：部分美国券商在**香港设有开户办事处**（如部分券商的 HK 办事处接受国际客户），可用香港地址 + 护照开户
- 成本：签证、机票、时间
- 优势：账户权益更完整（如 Schwab 的银行账户、支票、定投计划、部分银行联动）

---

### 1.5 路线对比速查

| | 盈透 IBKR | 富途/老虎/长桥 | 美国本土券商 |
| --- | --- | --- | --- |
| 大陆居民可开户 | ✅ 相对稳定 | ⚠️ 政策频繁调整 | ✅ 部分 |
| 需要赴港 | ❌ | ⚠️ 常需（至少一次核实） | ❌（但审核严） |
| 港股 | ✅ | ✅ 体验好 | ⚠️ 少数支持 |
| 美股 | ✅ | ✅（有门槛） | ✅ |
| 最低入金 | ~$100 | 常见 1 万港币 | $0–$100 |
| 佣金 | 分级，$0 起 | 分级，$0 起 | $0 |
| 中文客服 | 有（简中） | ✅ 很好 | 多数无 |
| 出金回内地 | ❌ 直接打内地通常不行 | ⚠️ 视政策 | ❌ |
| App/PC 体验 | 专业但复杂 | ✅ 好 | 好 |

<a id="us-2-w8ben"></a>

## 2. W-8BEN 怎么填（逐项说明）

W-8BEN 是**最重要的一张表**。填错 = 被多扣税或被要求补税。

### 2.1 Part I — 身份信息

| 行 | 填写 |
| --- | --- |
| **1. Name** | 你的英文姓名，与护照完全一致（姓 + 名，空格分隔） |
| **2. Citizen of (Country)** | `China` |
| **3. Permanent Resident of (Country)** | `China`（或 `N/A`，按实际） |
| **4. Mailing Address** | 你的实际居住地址（英文） |
| **5. Mailing Address if different** | 空着或填 `N/A` |
| **6. U.S. taxpayer ID Number** | 空着（除非你真的有美国 SSN/ITIN） |
| **7. Foreign TIN (optional)** | 可填中国身份证号（有些券商不要求，留空即可） |
| **8. Date of Birth** | 你的出生日期 |
| **9a. Permanent Resident Address** | 空着（若非美国税务居民） |
| **9b. Mailing Address in U.S.** | 空着 |
| **10. U.S. Citizenship** | `No` |
| **11. Country of Tax Residency** | `China` ← **关键** |
| **12. Foreign TIN (optional)** | 同第 7 项 |

### 2.2 Part II — 税收协定待遇

| 行 | 填写 | 说明 |
| --- | --- | --- |
| **13a. Is the beneficial owner claiming treaty benefits to reduce withholding?** | **`Yes`** | 中国与美国有税收协定 |
| **13b. Article and Paragraph** | 通常 `Article 10`（股息条款） | 按券商的模板提示填 |
| **13c. Special or Other Rates** | 通常留空 | 券商会自动按协定税率处理 |
| **13d. Add Rate / Condition** | 留空 | — |

> 💡 **不勾 13a 会怎样**：券商会按美国法定税率 **30%** 预扣你的股息。勾了并按协定待遇处理，一般是 **10%**。长期持有高股息 ETF（如 SCHD、VYM、O 类股票）时，10% 与 30% 的差距非常可观。

### 2.3 Part III — 豁免

| 行 | 填写 | 说明 |
| --- | --- | --- |
| **14a. U.S. source income subject to withholding under §871 or §881** | 如实（一般 `No`） | |
| **14b. Exemption claimed** | 空着 | |

### 2.4 Part IV — 签署

- **Signature**：手写签名（电子签署需按券商流程）
- **Date**：签署日期
- **Capacity**：留空（个人）
- **Print Name**：与签名一致

### 2.5 常见错误

| ❌ 错误 | 后果 |
| --- | --- |
| 税务居民国填 Hong Kong / Singapore | 适用 30% 法定预扣（除非香港与美有单独协定，但券商一般不认） |
| 不勾 13a | 30% 预扣 |
| 申请时"税务居民国"填了实际居住国但长期未搬回 | 需保持一致，否则后续可能被要求更正 |
| 姓名与护照不一致 | KYC 退回 |
| 过期后不续签（一般 3 年有效期，接近过期券商会提醒） | 失效后股息按 30% 预扣，直到你重新提交 |

> 💡 **W-8BEN 一般 3 年到期。** 到期前券商会邮件提醒，重新签署即可。**如果换了地址或税务身份，务必主动更新。**

<a id="us-3-flow"></a>

## 3. 开户全流程

```
第 1 步  官网/APP 注册，选择账户类型（Individual / Joint / Corporate）
第 2 步  个人资料：姓名、国籍、税务居民国、居住地址、职业、收入、净资产
第 3 步  身份文件：护照个人信息页（彩色全页）、住址证明（近 3 个月）
第 4 步  签署 W-8BEN
第 5 步  身份核验：自拍 + 活体 + 有时人脸比对 / 视频通话
第 6 步  税务问卷：Commonwealth Forms / Tax Forms → W-8BEN
第 7 步  等待合规审核                3–10 个工作日
第 8 步  首次入金（电汇 USD）          1–3 个工作日到账
第 9 步  账户激活 → 设置交易密码、绑定收款账户
第 10 步 开通市场权限（美股/期权需单独申请）
```

### 3.1 首次入金怎么操作（以 IBKR 为例）

1. 在 IBKR 后台 → `Fund Your Account` → 查看**该平台指定的收款银行信息**
2. **用你的香港银行账户或已有境外账户**发起一笔**电汇（Wire）**
3. 金额 ≥ 100 美元
4. 电汇附言/备注**留空或按券商要求填**（不要写奇怪的内容）
5. 备注里**不要写股票代码/公司名**，写"funding"或"deposit"即可
6. 到账后账户自动激活

> ⚠️ **必须从本人名下的账户汇出。** 用他人账户代汇会被判定为第三方入金，可能要求解释甚至冻结。

<a id="us-4-withholding"></a>

## 4. 股息预扣与中美税收协定

### 4.1 预扣税率

| 你的身份 | 美股股息预扣税率 |
| --- | --- |
| 美国税务居民 | 0%（自己申报） |
| 非美国税务居民，**不申请**协定待遇 | **30%** |
| **中国税务居民，提交 W-8BEN 并申请协定待遇** | **10%** ✅ |
| 香港税务居民 | 30%（香港与美国无股息协定，港资持有美股通常仍按 30%） |

> 💡 **有意思的结论**：如果你同时用香港券商和境外券商持美股，**通过提交了 W-8BEN 的境外券商（10%）比香港券商（30%）省一半**。这是很多人忽略的成本差异。

### 4.2 特殊情况：外国股息预扣税（FDII）

如果持有美国公司的**外国子公司**（如持仓所在公司注册在爱尔兰/百慕大等），美股股息可能同时涉及两层税：
1. 外国公司层面可能已扣税
2. 向你支付时美国再预扣

多数情况下合计不超过 30%，且中国居民通常不额外承担美国税负。

### 4.3 卖出股票的资本利得

**非美国税务居民**（含中国税务居民）出售美国上市公司股票，**通常不产生美国联邦所得税**，因为不是美国来源所得。

> ⚠️ 两个例外：
> 1. **NIWITs**：美国税法特殊定义的外国公司（如受美国股东影响度超 50% 等），其股东在特定条件下可能被视同持有美国来源所得。中国居民在 NIWIT 上被课税的概率低但存在，详见 IRS Publication 519。
> 2. **持有不超过 183 天的 NRDI**（非居民 Alien Individual）：出售美国股票的净资本利得要按 30% 征税，**除非有协定降低**。中税收协定的"资本利得"条款通常规定：非居民在来源国持有股票不超过 183 天时豁免征税，但**如果居民国（也就是中国）对该公司股票也征税**，协定待遇可能被否定。**长期持有（>183 天）则完全豁免。** → **结论：别做短线。**

### 4.4 实际算例

假设你持有 **$10,000 的 SCHD**（年化股息率约 3.5%，约 $350/年）：

| 券商 | 预扣率 | 每年实收 | 差额 |
| --- | --- | --- | --- |
| 已提交 W-8BEN（协定待遇） | 10% | **$315** | — |
| 未申请/未提交 | 30% | $245 | **-$70/年** |

持有 $100,000 时，差额是 **$700/年**。这足以影响你的资产配置决策。

## 5. 出金路径

### 5.1 常规出金

| 券商 | 提现方式 | 费用 | 备注 |
| --- | --- | --- | --- |
| IBKR | 电汇（Wire） | 按券商标准（常见 $15–$25） | 提现到本人名下境外账户 |
| IBKR | 部分场景支持 ACH | 较低 | 需美国账户 |
| 富途/老虎等 | 银行转账（本地/电汇） | 常见 HKD 50–100 / USD 10 | 提现到同名香港账户 |
| 美国本土券商 | ACH | 通常免费 | 需美国账户 |

### 5.2 出金回内地的现实

**这是路线 C 最大的坎。** 常见情况：

| 路径 | 可行性 | 说明 |
| --- | --- | --- |
| 券商 → 香港同名账户 → 汇回内地 | ⚠️ 受个人购汇额度与银行真实性审核约束 | 银行会问资金用途，证券投资收益汇回是合法用途，但单笔金额大时需要说明 |
| 券商 → 内地银行卡（部分平台支持） | ❌ 极少 | 大多数境外券商**不接受**内地银行卡作为提现目标（合规要求 + 收汇行限制） |
| 通过银联卡在境外消费 | ⚠️ 有限 | 属于消费而非投资，金额有限度 |
| 通过境外同名账户留存境外 | ✅ 最省心 | 资金留在境外继续投资，不回国 |

> 💡 **实践建议**：把境外券商当作"境外资产池"，盈亏留在境外循环。不要为了"把钱变回人民币"而反复折腾——每次换汇 + 汇款都是实实在在的成本（1%–2%），而且增加了外汇管理的操作风险。

### 5.3 涉税提示

**中国税务居民**的境外所得需要依法申报（见 [08 税务与合规](08-tax-compliance.md)）。券商每年会出具税务汇总文件（有的叫 Consolidated 1099 / 税务报告 / 月结单），**请保存好**，这是申报依据。

<a id="us-6-rejections"></a>

## 6. 常见被拒原因

| 原因 | 说明 | 怎么办 |
| --- | --- | --- |
| **地址不一致** | 申请表、证件、住址证明三个地址对不上 | 全部统一 |
| **IP/地址国家不符** | 人在国内、用美国地址 | 有时可通过视频核验解决，有时不行 |
| **住址证明不认可** | 只有中文、只有发票、超过有效期 | 见 [02.2](02-prepare.md#prepare-2-2-get-proof) |
| **文件模糊** | 手机翻拍反光 | 彩色扫描 |
| **第三方代为操作** | 家人/代操作者被要求出镜 | 本人完成 |
| **已有被封账户** | 同名账户曾有违规 | 换券商 + 换邮箱 |
| **平台政策限制** | 该平台已暂停向大陆居民开放 | 换平台，别硬刚 |
| **税务问卷填错** | 把税务居民国填成实际居住地 | 重新提交 W-8BEN |
| **视频核验排期太长** | 海外时段排队 | 耐心等，不要重复提交（重复提交可能被标记） |

> 💡 **被拒后的标准流程**：① 看拒信/邮件里的具体理由；② 逐条补材料；③ 通过客服工单回复并要求人工复核；④ 仍不行 → 换平台重开（注意：**不要用同一批造假材料**）。

## 7. 美股账户建立后的设置清单

```
[ ] W-8BEN 已提交且状态为有效（确认预扣率显示 10%）
[ ] 已设置分红再投资（DRIP）或现金派息（按你的偏好）
[ ] 已设置预留买股计划（若想定投）
[ ] 已开启 2FA（Google Authenticator / 硬件密钥更安全）
[ ] 已绑定提现账户（与入金账户一致）
[ ] 已记录券商客服电话/工单入口（出金遇问题时用）
[ ] 已了解结算规则：美股 T+1 交收、卖出资金 T+1 可提（现金账户）
[ ] 已确认货币转换（FX）费率与最低收费
[ ] 已了解 SEC/TAF/ORF 规费（卖出时收取，见第 07 章）
```
