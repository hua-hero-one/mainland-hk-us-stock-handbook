> 部分券商与银行的 App、开户页面、验证码接口在**内地网络下无法完成提交**——典型表现是提交后一直转圈、验证码收不到、上传证件失败、提示"当前地区不支持"。

## 这是什么

这是一份**可执行的操作手册**，不是"暴富指南"。

内容围绕一个具体问题展开：**我是中国大陆居民，我想买港股/美股，应该怎么一步步做？**

回答里会明确区分三类东西：

| 标记 | 含义 |
| --- | --- |
| ✅ **合规路径** | 有监管依据、可解释、可复述的正规做法 |
| ⚠️ **灰色地带** | 有人这么做，但监管状态不明或随时可能收紧，风险由个人承担 |
| 🚫 **红线** | 明确违法或高概率导致冻卡/清退/立案，不要碰 |

## 三句话版本

1. **港股最容易，美股次之，但"开户"从来不是瓶颈，"入金"才是。**
   99% 的翻车发生在钱怎么出去、怎么回来，而不是怎么填表。

2. **资金必须走"银行 → 银行"的路。**
   内地购汇 → 香港同名银行账户 → 券商。这条路慢一点，但经得起查。任何"地下钱庄""对敲换汇""虚拟货币出金"都是 🚫 红线。

3. **一切都可能变。**
   港美股开户政策近几年高频调整，本手册写的每一条具体政策都可能已经过期。**动手前请去 [12 信息来源](docs/12-sources.md) 列出的官方渠道确认最新口径。**
